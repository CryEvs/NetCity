Руководители проекта - редактирование

Вы можете назначить руководителем проекта сотрудника из любой школы.

В графе Образовательная организация выберите школу, из которой хотите назначить руководителя проекта. Затем в графе Группа пользователей выберите группу, к которой он принадлежит (пользователь с ролью учителя, завуча или администратора), поставьте галочку справа от его имени на экране и нажмите кнопку Сохранить.
