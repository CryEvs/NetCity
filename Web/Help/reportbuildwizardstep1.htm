Шаг 1 - Наименование отчёта

Наименование отчета

На первом шаге вам нужно задать наименование отчета, его тип (указывается только в интерфейсе Управления образования), название группы отчетов и, если нужно, то поясняющий комментарий.

Для наглядности, мы создадим при помощи «Конструктора отчетов» новый отчет под названием «Список мальчиков 90-91 гг. рождения (для военкомата)» и подробно рассмотрим каждый шаг процесса его создания.

Прохождение этапов создания отчета будет отображаться на каждом шаге в виде таблицы в левой части экрана. С помощью нее вы можете в любой момент вернуться к любому из пройденных шагов, нажав на соответствующую ссылку.

Сначала необходимо ввести название отчета - «Список мальчиков 90-91 гг. рождения (для военкомата)», в типе отчета указать - Отчет ОО (это поле будет присутствовать, если отчёт строится в модуле «Управление образования»), в поле «Комментарии» добавить пояснение, и выбрать при необходимости группу, к которой будет относиться отчет. После ввода этих данных необходимо нажать кнопку «След. >>» для перехода на Шаг 2 - Выбор объекта данных для запроса.
