Участники проекта - редактирование

В графе Раздел вы можете выбрать любой раздел, для которого назначаете участников проекта.

В графе Образовательная организация выберите школу, из которой хотите выбрать участников проекта, затем в графе Группа пользователей выберите категорию пользователей. В полученном списке отметьте галочками нужных участников и нажмите кнопку Сохранить.
