Итоговые отметки

Для выставления итоговых отметок нажмите в таблице название конкретного учебного периода (четверть, триместр, полугодие и др.), или, если это выставление оценок за весь год, на ссылки Год, Экз., Итог. Вы окажетесь на экране Редактирование итоговых отметок.

Право доступа на редактирование итоговых отметок (по умолчанию) задано для учителя, который ведет данный предмет в данном классе, а также для классного руководителя данного класса.

Можно ли выставить итоговые отметки, не выставляя текущих отметок?
Для выставления итоговых отметок необязательно вводить расписание либо заполнять текущие отметки в классном журнале. В начале внедрения системы именно так и следует сделать: сначала выставить итоговые отметки, что не займёт много времени, но позволит получить наглядные отчёты по итоговой успеваемости, тем самым покажет пользу от системы "Сетевой Город" для завуча, учителя и классного руководителя.

Какая минимальная информация должна быть введена в систему для выставления итоговых отметок?
Необходимо предварительно:
·правильно указать типы учебных периодов для всех классов;  
·ввести списки учащихся по классам;  
·распределить учащихся по подгруппам для отдельных предметов (см. инструкцию по созданию подгрупп).  

Разрешено ли выставление итоговых отметок "задним числом"?
В текущей версии системы время выставления итоговых оценок не ограничено. Можно выставить итоговые отметки за любой учебный период - прошедший или текущий.
(В отличие от текущих отметок, для которых администратор системы может сделать соответствующую настройку.)

Особенности выставления итоговых отметок в случае деления на подгруппы
Класс может делиться на подгруппы по определённому предмету, причём ученики могут свободно переводится из подгруппы в подгруппу - но в любом случае действует правило: для ученика по одному предмету в одном классе может быть только одна итоговая отметка.

См. также Правила учёта количества учащихся в отчётах.

Вы можете экспортировать итоговые оценки в таблицу формата MS Excel с помощью кнопки . Подробнее об этой возможности вы можете прочитать на странице Экспорт данных из системы "Сетевой Город".
