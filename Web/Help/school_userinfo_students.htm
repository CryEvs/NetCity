Сведения об ученике
Персональные данные (ПДн) учащихся доступны только авторизованным пользователям с соответствующими правами доступа. Согласно Федеральному закону № 152-ФЗ "О персональных данных", для обработки ПДн в образовательной организации необходимы письменные согласия субъектов ПДн. См. формы согласий на обработку ПДн для родителя и для ребёнка в разделе Ресурсы -> Документы -> Предустановленные.

Чтобы просмотреть краткие сведения об ученике, пользователю достаточно иметь право доступа Просматривать краткие сведения об учениках и родителях. К кратким сведениям относятся:
·ФИО,  
·фотография,  
·дата рождения,  
·пол,  
·класс,  
·e-mail,  
·предпочтительный способ связи,  
·домашний телефон,  
·мобильный телефон,  
·ФИО родителей со ссылками на их краткие сведения,  
·изучаемый иностранный язык,  
·номер личного дела ученика.  

В полные сведения об учащемся входят графы:
· ФИО;  
· Имя на экране - это то имя, которое отражается в общих списках пользователей, например, на странице Ученики. Для учеников, по умолчанию, оно выглядит так: «Иванов Иван»;  
·Имя пользователя - это логин, то есть имя, под которым пользователь входит в систему.

Редактирование сведений об ученике
Для редактирования сведений у вас должно быть право доступа Редактировать все сведения об учениках и родителях. По умолчанию, им обладают пользователи с ролью администратора, завуча и секретаря. Пользователям с ролью учителя рекомендуется предоставить отдельное право Редактировать сведения об учениках и родителях в своем классе.
В анкете учащегося можно указать его родителей, после чего появятся прямые ссылки на анкеты выбранных родителей.

К анкете можно присоединить и файл совершенно произвольного формата (например, характеристику ученика и т.п.). Для этого воспользуйтесь кнопкой Присоединить файл.
Нажав на расположенную справа в графе кнопку Изменить, вы попадёте на экран, где можно выбрать значения параметра из списка.
Так, для графы Социальное положение могут быть выбраны следующие значения справочника: Дети, оставшиеся без попечения родителей, Лишение родителей родительских прав, Дети, проживающие в малоимущих семьях и др.

Поле "СНИЛС"
Поле СНИЛС, если оно заполняется, должно быть задано в формате: 123-456-789 12
(три цифры, дефис, три цифры, дефис, три цифры, пробел, две цифры).
Причём последние две цифры - это контрольная сумма, которая позволяет проверить правильность ввода СНИЛС.

Система автоматически фиксирует информацию, кто и когда редактировал ПДн пользователей (см. Журнал изменений сведений о пользователях).

Сведения о движении учащегося
Поле Движение в сведениях об ученике содержит "историю" движения ученика между образовательными организациями. (Данное поле отображает движение данного ученика между любыми школами, а не только движение относительно текущей школы).
Как только создаются соответствующие приказы в Книге движения учащихся, поле Движение в сведениях об ученике автоматически изменяется. Данное поле содержит сведения:
·о зачислении,  
·о выбытии,  
·о выпуске,  
и не содержит сведений о внутришкольном движении (перевод из класса в класс / перевод на следующий год).
