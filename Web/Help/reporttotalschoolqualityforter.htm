Сводный отчёт об успеваемости и качестве обучения по школе

Данный отчёт позволяет анализировать успеваемость и качество знаний по итогам учебных периодов. Далее приведены формулы расчёта для 5-балльной шкалы (хотя отчёт работает не только для 5-балльной шкалы):

Процент успеваемости класса – рассчитывается путём сложения всех учащихся, которые учатся на 3, 4, 5, и делением этой суммы на общее количество учащихся в классе.  
Процент качества класса – рассчитывается путём сложения всех учащихся, которые учатся на 4 и 5, и делением этой суммы на общее количество учащихся в классе.  
При этом знаменатель рассчитывается так:
(Общее кол-во учащихся) = (Все учащиеся) - (Освобождённые) - (Не получившие отметок).  

Другие нюансы расчёта этих показателей можно посмотреть в разделе Формулы показателей успеваемости.
См. также Правила учёта количества учащихся в отчётах.

Аналогичным образом вычисляются показатели по каждой ступени и по школе в целом.
Примечание: При подсчёте %% успеваемости и качества по ступени или по школе, в этом отчёте учитываются только учащиеся начиная со 2-го класса (нулевой и 1-й классы не учитываются, причём независимо от системы оценивания, которая в них настроена).
