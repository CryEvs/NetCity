Форма № ОШ-5. Титульный лист
Форма № ОШ-5 предоставляет сведения о вечернем (сменном) общеобразовательном учреждении. На титульном листе Формы № ОШ-5 указываются Наименование отчитывающейся организации, код по ОКПО, код по ОКАТО и код по ОКОГУ.
Сверху и снизу на титульном листе есть ссылки на другие пункты Формы № ОШ-5. Для перехода на них нажмите на соответствующую ссылку левой кнопкой мыши: Титульный лист : пп.I-II : п.III : пп.IV-V : пп.VI-VIII : пп.VI-VIII

В ОШ-5 сведения о составе школы автоматически подсчитываются на начало текущего учебного года (как указано в титульном листе).

Пример: сейчас идет 2009-2010 учебный год, в формах ОШ будет авторасчёт данных по состоянию на 20 сентября 2009 г.

Печать Формы № ОШ-5
Если титульный лист готов, то его можно распечатать. Для этого нажмите кнопку Для печати. В новом открывшемся окне броузера нажмите кнопку Печать (Print). Таким же способом вы можете распечатать все остальные листы отчета.
Форма № ОШ-5 заполняется один раз в год, подписывается руководителем общеобразовательного учреждения и должностным лицом, ответственным за заполнение формы, с указанием номера контактного телефона и даты заполнения, и сдается не позднее, чем через 15 дней после начала занятий.

Примечание: Чтобы Форма № ОШ-5 была доступна и в следующем учебном году, ее надо закрыть с помощью соответствующей кнопки.
