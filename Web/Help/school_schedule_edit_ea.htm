Составить расписание

Данный экран позволяет внести в расписание занятия по внеурочной деятельности (ВД).

Расписание по ВД составляется аналогично расписанию учебных занятий.

Можно ли создать занятия ВД, которые пересекаются по времени с обычными уроками?
При сохранении расписания происходят проверки на пересечения занятий по времени.
Если есть такие учащиеся, которые посещают в одно и то же время занятия по ВД и обычные уроки, - то система предупредит об этом. Несмотря на предупреждение, расписание ВД всё равно можно сохранить, в таком случае занятие ВД наложится по времени на обычный урок.

Как задать расписание звонков для ВД?
При составлении расписания по ВД используется по умолчанию "Основное расписание звонков", но можно использовать и любое другое расписание звонков. Для этого предварительно сделайте следующее.
1. Перейдите на экран Расписание -> Время уроков, нажмите кнопку Назначение вариантов  
2. Выберите Уровень = "Группы внеурочной деятельности".  
3. Определите, какой вариант расписания звонков будет использован в каждой группе ВД.
