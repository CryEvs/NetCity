Расписание школы по дням недели (для ученика)
На закладке "Неделя" вы можете самостоятельно выбрать вид расписания, который вам в данный момент наиболее удобен. Это может быть расписание по дням недели, расписание для класса или предмета.
Расписание по дням недели составлено так, чтобы вы могли увидеть когда, в каких кабинетах и по каким прежметам в вашем классе будут проходить занятия на выбранной неделе.

Печать расписания
Любой вид недельного расписания вы можете просмотреть в удобном для печати виде, нажав кнопку . И вывести на печать, в новом открывшемся окне браузера нажав кнопку Печать (Print). Кроме того, есть возможность экспорта расписания в таблицу формата MS Excel с помощью кнопки . Подробнее об этой возможности вы можете прочитать на странице Экспорт данных из системы "Сетевой Город".

Расписание школы по дням недели (для родителя)
У пользователей с ролью родителя закладка Неделя выглядит так же, как у ученика, с той разницей, что есть дополнительный выпадающий список Ученики. Этот список предназначен для тех родителей, у которых в школе учатся сразу несколько детей. Это позволит выбрать расписание нужного ребёнка.
