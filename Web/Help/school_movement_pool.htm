Выпускники и выбывшие


На этом экране находится так называемый "список свободных учеников": это список учеников, выбывших по разным причинам из образовательных организаций, которые располагаются на одном сервере системы "Сетевой Город". Это позволяет организовать единое пространство для переводов учащихся в пределах муниципального образования или региона. Учащийся, выбывший из одной ОО, становится доступным для зачисления в другую ОО, с сохранением его «истории движения» и личного дела.

По умолчанию, доступ к экрану Выпускники и выбывшие имеет только пользователь с ролью администратора системы в каждой школе. Он может просматривать список свободных учеников, выбывших непосредственно из его школы.

Выберите параметры фильтров, затем нажмите кнопку Загрузить для отображения списка. Нажав на треугольник правее кнопки Загрузить, можно настроить список выводимых столбцов в таблице.

Категории доступности
В этом поле можно выбрать категорию: Выпуск или Выбытие.
Внутри каждой категории можно просмотреть следующие списки:
·Доступные для зачисления - учащиеся, которые могут быть зачислены в любую ОО, расположенную на данном сервере системы,  
·Все - "Доступные для зачисления" плюс недоступные (Архив).  

Категорию Архив следует назначать учащимся, закончившим школу или переехавшим в другой город. Информация о них будет доступна в режиме "Только чтение". Они НЕ будут видны при зачислении учащихся в какую-либо ОО на этом сервере, что исключит возможную путаницу в работе.

Чтобы ученика из категории Доступные для зачисления переместить в Архив (недоступные), необходимо нажать на нужную фамилию, и в открывшемся окне Сведения об ученике изменить категорию на Архив, указать причину, по которой ученик перешел в категорию недоступных.

Внимание! Обратную процедуру - перевод ученика из категории Архив (недоступные) в категорию Доступные для зачисления может осуществить только пользователь Администратор сервера. Кроме категорий Выпуск и Выбытие он также может редактировать категорию Архив.
