Вход пользователей с использованием ЭЦП

Пользователи могут входить в систему "Сетевой Город. Образование" с использованием электронной цифровой подписи (ЭЦП), что обычно реализуется посредством электронного USB-ключа.

Данная возможность реализована только для сотрудников Управления образования в системе "Сетевой Город. Образование".

Как правило, электронный USB-ключ, содержащий ЭЦП, снабжён уникальным кодом - отпечатком сертификата ЭЦП.

В личной карточке каждого пользователя Управления образования есть поле "Отпечаток сертификата ЭЦП". Для использования ЭЦП необходимо, чтобы:
1) в личной карточке данного пользователя это поле было заполнено соответствующей информацией;
2) на рабочем месте данного пользователя был установлен сертификат ЭЦП;
3) на рабочем месте данного пользователя использовался браузер Internet Explorer.

После этого на странице входа для Управления образования нужно выбрать ссылку "Вход с использованием ЭЦП". На открывшемся экране будет выведено приглашение вставить ключ с сертификатом ЭЦП в порт USB и нажать кнопку "Продолжить".

В то же время, для любого сотрудника Управления образования сохраняется возможность войти в систему и без использования ЭЦП, т.е. с помощью логина и пароля.
