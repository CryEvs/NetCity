Форма № ОШ-5 п.IX
В пункте IX указываются сведения о помещениях общеобразовательного учреждения. В частности, приводятся данные о количестве и площади собственных помещений общеобразовательного учреждения, не принадлежащих другим организациям, количестве и площади помещений другого образовательного учреждения, используемых для занятий, количестве и площади помещений, принадлежащих предприятиям и организациям, также используемым для занятий.
Форма № ОШ-5 заполняется один раз в год, подписывается руководителем общеобразовательного учреждения и должностным лицом, ответственным за заполнение формы, с указанием номера контактного телефона и даты заполнения, и сдается не позднее, чем через 15 дней после начала занятий.

Авторасчет
В системе "Сетевой Город" на каждой из страниц Формы № ОШ-5, кроме титульного листа, есть возможность автоматического заполнения полей с помощью кнопки Авторасчет. Данные можно потом при необходимости исправить или ввести вручную.

Печать сведений и переход на другие страницы
Сверху и снизу этой страницы есть ссылки на другие пункты Формы № ОШ-5. Для перехода на них нажмите на соответствующую ссылку левой кнопкой мыши: Титульный лист : пп.I-II : п.III : пп.IV-V : пп.VI-VIII : п.IX
Введенные сведения можно распечатать. Для этого нажмите кнопку Для печати. В новом открывшемся окне броузера нажмите кнопку Печать (Print).
