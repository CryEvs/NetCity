Коллекция ресурсов

Этот экран предоставляет доступ к электронным образовательным ресурсам (ЭОР) для всех уровней образования. Ресурсы могут быть использованы на различных этапах обучения при различных формах организации учебного процесса. Для того чтобы пользоваться "Коллекцией ресурсов", требуется Flash-модуль в вашем браузере (обычно предустановлен на всех настольных компьютерах).

Поиск ЭОР по "Коллекции ресурсов" осуществляется простым интуитивным способом через панель фильтров слева или вводом ключевых фраз в строку поиска.

По умолчанию, большинство ресурсов представлено в демонстрационной версии. Чтобы ваша школа получила доступ к полной версии каждого ЭОР, уполномоченный сотрудник школы должен обратиться в компанию "Новый Диск" по e-mail: school@nd.ru .

Коллекция постоянно пополняется.
