Отчет "Динамика среднего балла ученика"
Данный отчет позволяет проследить, как изменялась успеваемость (средний балл) конкретного ученика по сравнению со средней успеваемостью его класса, в табличном и графическом видах. Отчет показывает успеваемость ученика не только по итоговым отметкам, но и по срезовым работам. Средний балл вычисляется по всем предметам в классе, в зафиксированный момент времени (итоговая отметка/срезовая работа).
Для итоговых отметок в заголовке таблицы отражается название учебного периода, для срезовой работы - дата срезовой работы. Если по разным предметам срезовые работы назначены на разные даты, каждая попадает в таблицу в виде отдельного столбца, если на один день назначено несколько срезовых работ – по ним вычисляется среднее.
