Информация о детях, имеющих рекомендации ПМПК на обучение

Данный отчёт отображает список учащихся, у которых в личной карточке заполнено поле "Решения комиссий", причём указан тип комиссии "ПМПК".

Фильтр "Вид нарушения" позволяет выбрать конкретный вид нарушения (вид ограничения возможностей здоровья), который был задан в поле "Решения комиссий".

Отчёт доступен для сотрудников школы, которые имеют право доступа Просматривать отчёты по детям с особыми образовательными потребностями. По умолчанию, это право доступа выставлено для ролей:
·Администратор  
·Завуч  
·Медицинский работник  
·Психолог / Социальный педагог
