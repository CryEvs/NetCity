Расписание уроков и мероприятий на день

Выберите в фильтре Вид подходящий вид расписания:
·По времени - выводится таблица расписания, упорядоченная по времени проведения;  
·По кабинетам - выводится таблица, позволяющая наглядно увидеть занятость кабинетов (доступно только сотрудникам школы).  

Далее выберите в фильтрах:
·День - желаемая дата (по умолчанию сегодняшний день);  
·Учитель - позволяет выбрать конкретного учителя, чьё расписание нужно просмотреть, или выбрать значение Все. (Выбор учителей возможен, только если у вас есть право доступа Просматривать расписание для всех классов).  
·Вид деятельности - позволяет выбрать только предметы по учебному плану, или только внеурочную деятельность, или оба варианта вместе.  
·Класс - позволяет выбрать нужный класс или сразу несколько классов.  

Если в вашей школе есть несколько вариантов расписания звонков, то дополнительно можно выбрать Вариант. Если есть несколько смен, то можно выбрать Смену.

Если вы сотрудник школы, имеющий право доступа Составлять расписание и определять список кабинетов ОО, то вы можете щёлкнуть в ячейку таблицы, где выводится урок, - чтобы быстро перейти к редактированию расписания в данный день в данном классе.

Замечание: для вида "По кабинетам" в таблицу включаются только кабинеты с признаком "Учебное помещение".

Расписание для ИУП-классов
Если в вашей школе есть классы с типом учебного плана "Индивидуальный", то в фильтре Класс они будут доступны для выбора только в случае, если в этих классах есть ученики.

Расписание для ученика и родителя
Если вы ученик или родитель, то расписание будет доступно только в режиме просмотра.
Если у родителя обучается в школе двое и более детей, то можно выбрать нужного ребёнка в поле Ученик.
