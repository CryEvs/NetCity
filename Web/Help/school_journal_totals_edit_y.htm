Выставление отметок по итогам года

В данном экране можно выставить отметки в графах "Год", "Экзамен", "Итог".

1. Выставление отметок в графе "Год"
Для вашего сведения выводятся итоговые отметки учащихся за все учебные периоды (четверти/триместры/полугодия).
Проставьте учащимся годовые отметки и нажмите кнопку Сохранить.


2. Выставление отметок за экзамены
Для того чтобы выставить экзаменационные отметки, нужно определить типы экзаменов для данного класса и предмета. После этого проставьте учащимся экзменационные отметки и нажмите кнопку Сохранить.

·Если для данного экзамена установлен признак "По выбору"  
Рядом с полем оценки отображается "галочка", которую нужно отметить для учащихся, выбравших этот тип экзамена. Если ученику выставлена отметка, то "галочка" будет отмечена автоматически.  

·По какой шкале выставляются отметки за экзамены?  
Система оценивания для экзамена не обязательно совпадает с системой оценивания для соответствующего предмета.  
Для типа экзамена "ЕГЭ" - можно выставить отметки только по 100-балльной шкале.  
Для других типов экзаменов используется система оценивания, которая настроена в экране Справочники -> Типы экзаменов в интерфейсе Администратора сервера. (Для каждого типа экзамена можно настроить свою систему оценивания: балльная или зачёт-незачёт.)  

·Результаты ЕГЭ и ОГЭ  
Система позволяет учащимся просматривать свои официальные персональные результаты ЕГЭ/ОГЭ, а родителям - просматривать результаты ЕГЭ/ОГЭ своего ребёнка. Для этого:  
1) Сотрудники вышестоящего Управления образования должны ввести в систему официальные результаты ЕГЭ и ОГЭ при помощи импорта файла, полученного из РЦОИ;  
2) Cотрудники школы должны убедиться в соответствии фамилий учащихся на экране Результаты сдачи ГИА.  


3. Выставление отметок в графе "Итог"
Отметку в графе "Итог" можно выставить ученику, только если данному ученику была выставлена отметка в графе "Год".

Удобно отметить галочку "Автоматическое выставление предлагаемых оценок", после чего система автоматически заполнит графу "Итог" годовыми отметками.
Внимание! Эти предлагаемые отметки ещё не сохранены в базу данных системы, для их сохранения нужно явно нажать кнопку Сохранить. Вы можете свободно изменить предлагаемую отметку.


Выставление отметок учащимся, переведённым условно
