Создание нового отчёта

Для кого предназначен Конструктор отчетов
"Конструктор отчетов" - это инструмент для создания запросов пользователей к базе данных. Предназначен для сотрудников школы с ролью администратор системы, а также в системе «Сетевой Город. Образование» - для сотрудников Управления образования, не обязательно близко знакомых с программированием, но имеющих начальные знания в области баз данных. Технология данного "Конструктора" уникальна и позволяет не привлекать сложное профессиональное ПО (которое потребовалось бы приобретать отдельно), а строить запросы и отчёты только из Web-интерфейса системы "Сетевой Город".
Однако следует помнить, что работоспособность и эффективность созданных отчётов зависит от правильной связи объектов между собой. Для этого важно изучить структуру отношений между объектами «Конструктора отчётов», которая изложена в отдельном документе под названием "Руководство по Конструктору отчётов".

Чтобы быстро научиться создавать свои отчеты с помощью "Конструктора", можно воспользоваться следующими способами:
а) посмотреть наглядные примеры отчётов, приведенные в отдельном документе "Руководство по Конструктору отчетов";  
б) взять готовый предустановленный отчет на экране Дополнительные отчеты, сделать его копию и разобраться, как он устроен.

Типы отчётов
Отчеты, созданные с помощью конструктора отчетов, делятся на два типа: внутришкольные (или Отчеты ОО) и общесистемные. Внутришкольные отчеты - это отчеты по данным одной школы, а общесистемные - по данным нескольких школ. Внутришкольные отчеты доступны для всех сотрудников школы на экране Дополнительные отчеты после их опубликования. Общесистемные и Административные отчеты введены специально для пользователей с ролью «Управление образования» в системе «Сетевой Город» и будут видны только им.
Административные – это отчеты для межведомственных взаимодействий (напр., для доступа социальных служб города, ИДН и др. ведомств).

Создание нового отчёта
Чтобы создать новый отчет или отредактировать уже опубликованный, у вас должно быть право доступа Использовать конструктор отчетов. По умолчанию, таким правом обладает пользователь с ролью администратора системы. Процесс создания отчета состоит из 9 шагов, последним из которых является тестирование созданного отчета и его публикация. Чтобы приступить к созданию нового отчета нажмите кнопку Создать и вы окажетесь на Шаге 1 - Наименование отчета.

Группы отчётов
В системе отчеты можно разделять по смыслу - группировать их (например, можно создать группы "Отчеты для секретаря", "Отчеты РОНО" и др.). Чтобы добавить новую группу, нужно нажать кнопку Группы отчетов. После добавления группы на Шаге 1 - Наименование отчета для вашего отчёта можно выбрать нужную группу.

Статус отчёта
Отчеты, созданные с помощью конструктора отчетов, могут иметь один из трех статусов:
·Незаконченные (Нез.)  
·Редактируемые (Ред.)  
·Опубликованные (Опуб.)  
Если все девять шагов конструктора еще не пройдены, то отчет имеет статус незаконченный и редактируемый. После того, как отчет готов, последний шаг, после прохождения которого он будет доступен для сотрудников на экране Дополнительные отчеты, - это публикация. Такой отчет получает статус опубликованный. Опубликованный отчет может быть впоследствии отредактирован. В этом случае, на время редактирования (до очередной публикации) отчет получает статус редактируемый (но не незаконченный).

Предустановленные отчёты
Статус "Предустановленные" имеют отчёты, также созданные при помощи конструктора отчётов, но введённые в систему при её установке. Эти отчёты нельзя редактировать, в отличие от отчётов, созданных пользователями. Однако можно создать копию предустановленного отчёта и изменить эту копию.

Внутренние отчёты
Статус отчета все внутренние объединяет отчёты всех трёх видов, созданных пользователями, либо импортированных при помощи кнопки Импорт, либо добавленных Управлением образования. Этот статус назван так потому, что эти отчёты находятся внутри своей области видимости. Для пользователя ОО этой областью видимости является его учебное заведение, а для пользователя с ролью Управление образования (в системе «Сетевой Город») – это, соответственно, все школы, подчинённые этому Управлению образования.

Для обмена отчетами, созданными при помощи Конструктора, с другими школами - на экране Конструктор отчётов предусмотрена кнопка Импорт.
