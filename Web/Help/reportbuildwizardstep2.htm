Шаг 2 - Выбор объектов данных для запроса

Объекты данных для запроса

На этом шаге необходимо:
1.Выбрать объект в фильтре «Конечный объект данных», - это должен быть тот объект, информацию о котором вы желаете получить в отчете;  
2.После этого, система автоматически уменьшит «дерево зависимостей объектов», оставив только те «ветки», которые заканчиваются желаемым объектом;  
3.Вам следует выбрать самую простую «ветку», причём такую, чтобы в ней присутствовали все объекты, данные которых будут использованы в отчете.  

Внимание! Правильный выбор объектов для отчета - это важнейший этап построения отчёта. Это позволит легче пройти другие шаги "Конструктора отчётов", избежать ошибок. Рекомендуем прочитать раздел Нюансы использования "Конструктора отчетов" в документе под названием "Руководство по Конструктору отчетов".

Около каждого объекта данных есть синяя кнопочка с вопросительным знаком, нажав на которую, вы получите полное описание этого объекта, его возвращаемые поля и связи.
При наведении курсора мыши на объект «Ученики» выбранная «ветка» зависимостей объектов выделяется жирным шрифтом, а при нажатии на этот объект происходит переход на Шаг 3 - Выбор дополнительных объектов данных для запроса.
