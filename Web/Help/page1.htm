Титульный лист формы

Титульные листы форм госстатотчётности работают в системе похожим образом. Поэтому рассмотрим титульный лист на примере Формы № ОО-1.

На титульном листе Формы № ОО-1 указываются Наименование отчитывающейся организации, Почтовый адрес, Код формы по ОКУД, Код учреждения по ОКПО.

Переход на другие страницы формы
Фильтр Раздел позволяет выбрать другие страницы формы. На примере Формы № ОО-1:
Титульный лист 1.1 1.2 1.3 1.4 2.1.1.1 2.1.1.2 ... 3.4 3.5

Заполнение данных в формах
На титульном листе указана дата, по состоянию на которую должна быть заполнена данная форма. Например, Форма № ОО-1 учитывает сведения о школе, состав учащихся и т.п. по состоянию на 20 сентября.

На многих страницах форм, кроме титульного листа, есть кнопка Авторасчёт, которая позволяет автоматически заполнить поля данными из системы. Авторасчёт производится постранично, т.е. нажатие этой кнопки меняет только содержимое текущей страницы формы.
После авторасчёта данные не сохраняются в базе данных, а только отображаются на экране в соответствующих полях. Таким образом, есть возможность отменить авторасчёт, просто не сохраняя результаты его действий. Чтобы содержимое полей было сохранено в базе данных системы, нужно явно нажать кнопку Сохранить.

Важно! Независимо от наличия авторасчёта, содержимое любых полей формы можно исправить или ввести вручную.

Экспорт формы в Excel и печать формы
На титульном листе каждой формы есть кнопка Экспорт в Excel, по нажатию которой формируется файл формата Microsoft Excel 2003. Школа может загрузить этот Excel-файл в личный кабинет школы на сайте ГИВЦ: https://miccedu.ru.
Кроме этого, на каждой странице каждой формы есть кнопка Для печати, которая позволяет вывести данную страницу на печать стандартными средствами вашего браузера: в новом открывшемся окне нужно нажать кнопку "Печать" на панели инструментов браузера.

Для чего нужна кнопка "Закрыть форму"?
На титульном листе каждой формы есть кнопка Закрыть форму, которая фиксирует содержимое формы, делая невозможными её изменения. Форму необходимо закрыть, чтобы:
1.предоставить эту форму вышестоящему органу для формирования сводных форм госстатотчётности;  
2.обеспечить возможность заполнения этой формы в следующем учебном году. Если форма за прошедший год не закрыта, то в следующем учебном году эта форма будет недоступна.  

Важно! После нажатия кнопки "Закрыть форму", изменения формы в текущем учебном году невозможны.

Импорт формы
Кнопка Импорт на титульном листе формы позволяет загрузить в систему готовый файл в формате .xls.
Требования к файлу:
1.Файл должен иметь формат Microsoft Excel 2003. Если же файл был получен в более поздней версии Excel, то его нужно пересохранить именно в формате Microsoft Excel 2003 с расширением .xls (при помощи команды "Сохранить как..." в Excel).  
2.Структура файла (набор листов, таблиц, ячеек) должна строго соответствовать официальному шаблону соответствующей формы. Например, файл Формы № ОО-1 в требуемом виде можно получить из личного кабинета школы на сайте ГИВЦ: https://miccedu.ru.  
 
Как получить Формы ОО-1, ОО-2 и др. в прошлых периодах (за предыдущие учебные года)?
Бланки форм госстатотчётности могут обновляться (как правило, каждый год "Росстат" корректирует и утверждает новые редакции форм). Соответственно, в системе "Сетевой Город. Образование" бланки форм госстатотчётности в разных учебных годах могут выглядеть по-разному: может меняться количество разделов и содержимое разделов.

Чтобы получить формы за предыдущие учебные года, нужно в экране Статистическая отчётность изменить значение фильтра "Учебный год", после чего перейти в нужную форму.
