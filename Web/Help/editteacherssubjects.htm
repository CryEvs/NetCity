Предметы, преподаваемые учителем
В анкете каждого пользователя с ролью учителя необходимо отметить предметы, которые он преподает в школе. Если этого не сделать, то невозможно будет назначить учителю на экране Обучение->Предметы вести предмет в каком-либо классе. Соответственно, для учителя нельзя будет составить расписание и т.д.

Для обозначения предметов, которые ведет учитель в школе, отметьте их галочками и нажмите кнопку Сохранить.
