Результаты ЕГЭ

Данный отчёт выводит результаты ЕГЭ в вашей школе по каждому предмету.
В отчёт попадают данные только по 11-м (12-м) классам.
Это количественный отчёт, без фамилий учащихся.

Откуда берутся данные для этого отчёта?
Предварительно сотрудник Управления образования должен импортировать в систему Excel-файл с персональными результатами ЕГЭ, который получен из РЦОИ (региональный центр обработки информации).

Где можно увидеть персональные результаты ЕГЭ (с фамилиями учащихся)?
Персональные результаты ЕГЭ доступны сотрудникам школы на экране "Результаты сдачи ГИА".

Замечание 2. При расчёте граф "Набрали от 61 до 80 баллов" и "Высокобалльные работы (от 81 до 100 баллов)", при вычислении % от общего количества, предмет "Математика базовая" не участвует в расчёте. То есть:
Количество учеников = Приняло участие (Итого) - Приняло участие (Математика базовая)
и далее % от общего количества = Всего (Итого) * 100% / Количество учеников
