Сведения о родителе
Персональные данные (ПДн) родителей доступны только авторизованным пользователям с соответствующими правами доступа. Согласно Федеральному закону № 152-ФЗ "О персональных данных", для обработки ПДн в образовательном учреждении необходимы письменные согласия субъектов ПДн. См. формы согласий на обработку ПДн для родителя и для ребёнка в разделе Ресурсы -> Документы -> Предустановленные.

Чтобы просмотреть краткие сведения о родителе, пользователю достаточно иметь право доступа Просматривать краткие сведения об учениках и родителях. К кратким сведениям относятся: ФИО с фотографией, дата рождения, пол, домашний телефон, e-mail, предпочтительный способ связи, имена детей со ссылками на их краткие сведения.

Редактирование сведений о родителях
Для редактирования полных сведений о родителе должно быть право доступа Редактировать все сведения об учениках и родителях. По умолчанию, им обладают пользователи с ролью администратора или завуча. Пользователям с ролью учителя рекомендуется предоставить отдельное право Редактировать сведения об учениках и родителях в своем классе.

В поле Дети расположены ссылки на личные карточки детей этого родителя в данной школе. Ниже есть поля Помощь школе и Дата и результат обращения за помощью. Данные из этих полей будут использоваться для составления отчета Помощь родителей школе .

ФИО, Имя на экране, Имя пользователя
В системе "Сетевой Город" необходимо различать несколько терминов для идентификации каждого пользователя:
·«ФИО» - это фамилия, имя и отчество;  
·«Имя на экране» - это то имя, которое отражается в общих списках пользователей, например, на странице Родители. Для родителей, по умолчанию, система использует здесь ФИО;  
·«Имя пользователя» - это логин, то есть имя, под которым пользователь входит в систему.  
См. также Какие символы допускаются в логине и пароле.

Поле Мобильный телефон используется:
·при рассылке отчётов об успеваемости и посещаемости, а также другой информации на мобильный телефон родителей в виде SMS;  
·для восстановления пароля, в случае если пользователь забыл свой пароль для входа в систему.  
Поле Мобильный телефон должно состоять из 11 цифр, причём первая цифра должна быть 7. Пример корректного заполнения этого поля: 79021234567.

Поле СНИЛС, если оно заполняется, должно быть задано в формате: 123-456-789 12
(три цифры, дефис, три цифры, дефис, три цифры, пробел, две цифры).
Причём последние две цифры - это контрольная сумма, которая позволяет проверить правильность ввода СНИЛС.

Система автоматически фиксирует информацию, кто и когда редактировал ПДн пользователей (см. Журнал изменений сведений о пользователях).
