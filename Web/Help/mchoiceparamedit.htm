Параметры в виде списков

Социальное положение, Творческие объединения, Заболевания, Девиантное поведение, Предметы для ЕГЭ
Эти поля в анкете ученика являются списками, причём здесь можно выбрать более одного значения из списка. Отметьте галочками соответствующие значения и нажмите кнопку Сохранить. Набор значений в этих списках может изменяться пользователем с ролью Администратор сервера.

Выбор значения параметра "Помощь школе"
Этот параметр содержится в анкете пользователя с ролью родителя. Вы можете выбрать те виды помощи школе, которые способен оказать данный родитель. Список видов помощи можно отредактировать на экране Справочники пункта меню Управление -> Сведения о школе. Отмеченные виды помощи в дальнейшем смогут быть использованы для заполнения поля Дата и результат обращения за помощью в анкете пользователя. И затем, исходя из этих данных, можно будет получить отчет Помощь родителей школе.
