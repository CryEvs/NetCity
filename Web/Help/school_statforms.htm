Статистическая отчётность

Данный экран позволяет формировать следующие отчёты для вышестоящих организаций.

1. Первичные формы госстатотчётности:
Форма № ОО-1  
Форма № ОО-2  
Если с помощью фильтра "Учебный год" переключиться в предыдущие учебные года, то в экране "Статистическая отчётность" также доступны формы:  
Форма № ОШ-1  
Форма № ОШ-2  
Форма № ОШ-5  
Форма № ОШ-9  
Форма № 83-РИК  
Начиная с 2016-17 учебного года, эти первичные формы утратили силу, однако можно по-прежему получить из системы данные, сохранённые в них.  

2. Кнопка Заполнение отчётов для вышестоящих организаций ведёт в дополнительный модуль "Мониторинг системы образования" (в случае установки данного модуля на сервере региона).


Почему вместо кнопки отображается "Форма № ОО-1" - недоступна (то же самое для Формы № ОО-2 и др.)
Если вместо кнопки отображается надпись "Форма № ОО-1 недоступна", значит, в школе есть закрытые учебные годы (как минимум, один), в которых не закрыта Форма № ОО-1. Для того, чтобы вы смогли попасть в форму, необходимо последовательно закрыть формы за все предыдущие учебные годы. Для этого, с помощью выпадающего списка Учебный год, найдите закрытый учебный год, в котором доступна кнопка Форма № ОО-1, и войдите в неё. Затем в открывшемся экране "Титульный лист" нажмите кнопку Закрыть Форму № ОО-1. Аналогичным образом надо закрыть формы во всех закрытых учебных годах (но не в текущем!).

Примечание: Описанное выше справедливо для Формы № ОО-2 и всех других.
