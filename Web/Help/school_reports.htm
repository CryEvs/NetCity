Основные отчёты

Отчёты
На экране Отчёты размещён набор стандартных отчётов, наиболее востребованных в школах. По умолчанию, учителя и классные руководители могут просматривать отчёты только по своему классу, а пользователи с ролью администратора системы или завуча - отчёты во всех классах. (подробнее см.ниже Права на отчёты).

Избранные отчёты
Поскольку список отчётов для сотрудников школы достаточно большой, то предусмотрен удобный доступ к отчётам. Щёлкнув на название любого отчёта, сотрудник школы может нажать кнопку Добавить в избранные, после чего отчёт будет помещён в группу Избранные отчёты именно для этого сотрудника. При следующих входах в систему сотрудник сможет найти отчёт в этой группе.
Для учащихся и родителей отчётов намного меньше, поэтому нет возможности поместить отчёт в Избранные отчёты.

Примечание: В группах Итоги успеваемости и посещаемости (по классу) и Итоги успеваемости и посещаемости (по школе) отчеты строятся на основании итоговых отметок, а в группе Текущая успеваемость и посещаемость - на текущих оценках. Исключением из общего правила является Предварительный отчет классного руководителя за учебный период. В нем могут одновременно вычисляться показатели по текущим оценкам за текущий период и по итоговым за уже закончившийся.

Кроме этих стандартных отчетов, в системе "Сетевой Город" могут быть Дополнительные отчеты, созданные с помощью Конструктора отчетов. Чтобы ими воспользоваться, вы должны иметь право доступа Просматривать дополнительные отчеты.

В разделе Педагогический портфолио сам учитель может сформировать отчёты по результатам своей учебной деятельности, которые предназначены для прохождения аттестации педагога.

Права на отчеты
По умолчанию, пользователь с ролью учитель может получать отчеты только по тем предметам и тем классам, в которых он сам преподает. Если пользователь является классным руководителем, то он имеет право просматривать все отчеты, относящиеся к своему классу вне зависимости от того, какие предметы он преподает. Пользователь с ролью ученик, по умолчанию, может просматривать отчеты только для своего класса, с ролью родитель - отчеты для классов, в которых учатся его дети, с ролями секретарь и специалист по кадрам - просматривать только административные отчеты. Пользователи с ролями администратор системы и завуч, по умолчанию, могут просматривать любые отчеты в любых классах.
