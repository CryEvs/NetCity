Участники мероприятия

Этот экран доступен только сотруднику школы с признаком "Куратор одарённых детей". Здесь вы можете:

1) в блоке Информация о мероприятии - посмотреть подробности данного мероприятия;

2) в блоке Список участников:
·просмотреть список всех детей-участников мероприятия, которые были назначены в том числе в других школах другими кураторами;  
·назначить участников мероприятия из числа ваших подопечных.  

Важно: вы можете добавлять участников только из числа тех детей, в личных карточках которых Вы указаны как куратор данного ребёнка.
