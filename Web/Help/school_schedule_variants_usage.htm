Назначение вариантов расписания звонков

На этом экране можно назначить вариант на одном из уровней:
·Образовательная организация  
·Параллели  
·Классы  

Например, чтобы назначить своё расписание звонков для младших классов, нужно выбрать уровень "Параллели", затем в таблице напротив 1, 2, 3, 4 параллелей выбрать вариант "Младшая школа" (который был заранее создан в экране "Варианты расписания звонков").

Внимание! Назначение вариантов расписания звонков необходимо делать до составления расписания занятий. Изменить вариант расписания звонков можно только для тех параллелей и классов, для которых не создано расписание занятий.

Назначение расписания звонков является неизменным на весь учебный год.

Где используется назначенный вариант расписания звонков?
Варианты расписания звонков используются при составлении расписания для конкретной группы по предмету, в том числе для проверки пересечения уроков по времени.
Группа по предмету всегда связана с конкретным классом, в случае "классического" учебного плана (или с параллелью, в случае "индивидуального" учебного плана). При сохранении расписания, для этого класса (или ИУП-параллели) система определяет вариант расписания звонков, а для него, в свою очередь, определяет время уроков для каждого дня недели.
