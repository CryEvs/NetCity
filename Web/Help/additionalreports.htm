Дополнительные отчёты


Дополнительные отчеты - это отчёты, которые были разработаны пользователями системы с помощью Конструктора отчетов , в отличие от экрана основных отчётов, которые заложены в систему разработчиками.

Чтобы воспользоваться экраном "Дополнительные отчёты", вы должны иметь право доступа Просматривать дополнительные отчеты. По умолчанию, такое право есть у пользователей с ролью администратора, завуча или учителя.

После того как отчёт появился в экране "Дополнительные отчёты", есть возможность его дальнейшего изменения. А именно, с помощью "Конструктора отчётов" можно создать модифицированную копию, расширить набор запрашиваемых полей, условие их выборки и т.д. Все нюансы использования Конструктора отчётов описаны в отдельном документе "Руководство по Конструктору отчётов".

На данном экране представлен список разработанных пользователем отчетов, опубликованных в системе на данный момент. Статус опубликованные означает, что отчёты завершены и целостны. Таким образом, в списке дополнительных отчетов доступны только отчёты, гарантированно возвращающие результат при просмотре. Подробнее о возможных статусах отчётов вы можете прочитать по ссылке статус отчёта.
