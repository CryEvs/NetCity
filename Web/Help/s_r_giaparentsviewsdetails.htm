Ознакомление родителей с результатами ЕГЭ/ОГЭ (персональный список)

Данный отчёт позволяет сотруднику школы видеть пофамильный список учащихся, родители которых просмотрели результаты ЕГЭ/ОГЭ.

Как и в количественном отчёте "Ознакомление родителей с результатами ЕГЭ/ОГЭ", здесь фактом ознакомления считается именно просмотр результатов ЕГЭ/ОГЭ из учётной записи родителя. Ознакомление самого учащегося со своими результатами не учитывается.

Выберите вид экзамена:
·ЕГЭ - для получения отчёта по 11-м (12-м) классам,  
·ОГЭ - для получения отчёта по 9-м классам.  

Пример для ОГЭ:
в отчёте в алфавитном порядке выводятся все учащиеся 9 классов в таблице вида:

Для ЕГЭ отчёт строится аналогично, только рассчитывается по 11(12) классам.
