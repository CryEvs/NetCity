Сертификаты дополнительного образования

Только для системы "Сетевой Город. Образование" с подключенным модулем "Сертификаты дополнительного образования":

Сертификат дополнительного образования - именной документ (идентификационный номер), выдаваемый ребёнку, который устанавливает право родителей (законных представителей) ребёнка на оплату услуг за обучение по дополнительным общеразвивающим программам. Сертификат обеспечивает работу персонифицированного финансирования в сфере дополнительного образования.

В системе "СГО" работать с сертификатами ДО могут как сотрудники организации дополнительного образования (ОДО), так и сотрудники органов управления образованием.

На данном экране администратор ОДО может работать с реестром сертификатов дополнительного образования:
·просматривать сертификаты, выданные в данной ОДО;  
·выдавать (генерировать) новые сертификаты в данной ОДО.  

Просмотр списка сертификатов
Выберите параметры фильтров "Статус сертификата" и "Объединение", затем нажмите кнопку Загрузить.
В таблице будут выведены поля:
·Номер сертификата  
·ФИО учащегося  
·Дата рождения  
·Статус сертификата  
·Дата начала действия  
·Дата окончания действия  
·Документ, удостоверяющий личность  
·СНИЛС  

Нажав на треугольник справа от кнопки Загрузить и затем нажав кнопку "Настройки", вы можете отметить дополнительные поля для вывода в таблице.

Поиск сертификатов
В поле "Поиск" можно быстро найти нужный сертификат:
·по номеру сертификата - если ввести несколько цифр из номера;  
·по фамилии учащегося - если ввести несколько первых букв фамилии.  

Выдача новых сертификатов
Нажмите кнопку Добавить, после чего откроется окно создания нового сертификата.
1. В поле "ФИО учащегося" наберите первые несколько букв фамилии ребёнка. Система предложит выбрать из подходящего списка учащихся, причём только из тех, кому ещё не выдан сертификат.
2. Выберите ребёнка из предложенного списка. Система автоматически установит поля:
·"Дата начала действия" - будет предложена сегодняшняя дата;  
·"Дата окончания действия" - будет присвоена дата 18-летия ребёнка;  
·"Статус" - будет присвоено "Актуален".  
3. Нажмите кнопку Создать. Система сгенерирует и сохранит для ребёнка уникальный 10-значный номер сертификата.

Редактировать созданный сертификат (менять его дату начала действия и статус) может только сотрудник Управления образованием.

Более подробно о работе с сертификатами можно прочитать в отдельном "Руководстве пользователя модуля Сертификаты дополнительного образования".
