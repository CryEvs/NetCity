Создание/Редактирование образовательной области

Образовательная область используется для группировки предметов в таблице учебного плана. Ни в каких отчётах системы образовательные области не используются.

Для создания образовательной области нужно ввести только её название и нажать кнопку Сохранить. Нельзя создать две образовательные области с одинаковыми названиями.
