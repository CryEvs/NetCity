Создание/Редактирование подгруппы
Для создания подгруппы достаточно ввести ее полное и сокращенное название и нажать кнопку Сохранить.

Сокращенное название предмета нужно для компактного вывода расписания занятий, что актуально, например, при выводе расписания школы по дням недели для нескольких классов сразу.
