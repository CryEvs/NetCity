Добавление переноса

Перенос занятий на другой день
Для переноса дня выберите с помощью иконок, вызывающих календарь, дни с какого и на какой вы хотите перенести занятия. Напишите причину переноса.

Важно: При переносе расписание с одного дня полностью переходит на другой для всей школы. Будьте внимательны! Отменить или удалить перенос нельзя.
