Профили (специализации) учебного плана
Вы можете создать несколько классов одной параллели с разными профилями (специализациями). Например, 9а класс - физико-математический, 9б класс - гуманитарный. Профили определяются на Шаге 4. Профили (специализации) учебного плана мастера ввода данных, но их список может быть изменен. По умолчанию, в системе "Сетевой Город" создается один профиль - общеобразовательный. Все новые созданные профили будут отображаться в таблице Учебного плана, и по каждому из них в отдельности можно вводить свои часы.

Внимание: здесь нужно вводить профили, которые связаны с целыми классами. Если же на определённых предметах класс делится на группы по уровням освоения (напр., базовый, профильный, углубленный, расширенный), причём учащиеся разных классов объединяются вместе, - то нужно использовать функционал индивидуальных учебных планов.

Добавление профилей
Чтобы добавить новый профиль, нажмите кнопку Добавить. В новом окне введите название профиля, отметьте галочками параллели, которым он будет назначен, и нажмите кнопку Сохранить.

Изменение профиля в учебном плане
Если профиль в учебном плане необходимо изменить, сначала создайте новый профиль, как это описано выше, затем задайте его классам на экране Обучение->Классы: нажмите на гиперссылку в столбце Профиль для нужного класса, и вы попадете на страницу смены профиля. Смена профиля классу возможна только в том случае, если в текущем учебном году в данном классе не выставлено итоговых оценок.
После того, как новые профили будут связаны со всеми классами, на странице Учебный план можно вносить часы по предметам и вводить в учебный план новые предметы. Сохранение учебного плана автоматически свяжет классы с преподаваемыми в них предметами, и если вы вернетесь на экран Предметы, то сможете назначить учителей, преподающих предметы в конкретных классах.
