Предметы

Этот экран предоставляет информацию о том, какие предметы ведутся в классах и какие учителя их преподают. Благодаря выпадающему списку Вид, вы можете просмотреть эту страницу в двух вариантах: По классам и По учителям.

Предметы по классам
Вариант По классам даёт возможность узнать, какие учителя и какие предметы связаны с выбранным классом, а также сколько часов отводится на каждый из них в Учебном плане.
Вы можете изменить учебные периоды, в которых преподается предмет, если нажмёте соответствующую ссылку.

Предметы по учителям
Вариант По учителям дает возможность получить информацию о выбранном учителе: в каких классах и какие предметы он преподаёт.

Система оценивания
Выбрав конкретные класс и предмет, можно задать для них систему оценивания:
·Балльная (по умолчанию),  
·Зачёт-незачёт,  
·Не оценивается.  
Изменить систему оценивания можно только в том случае, если по данному предмету в классе ещё не выставлено ни одной итоговой отметки.

Как связать новый предмет с классом
При создании класса с ним автоматически связываются предметы, по которым проставлены часы в учебном плане. Для добавления нового предмета в класс, пользователь должен иметь право доступа Редактировать предметы и подгруппы в классах. По умолчанию, такое право доступа есть у пользователей с ролями администратора или завуча.
Чтобы связать предмет с классом, нужно:
1) создать предмет на экране Планирование->Предметы (Внимание! Не текущего пункта меню Обучение);  
2) на экране Управление->Сотрудники сопоставить в анкете хотя бы одному из учителей этот предмет в строке Преподаваемые предметы;  
3) на экране Учебный план проставить часы по этому предмету для всех классов, в которых он будет преподаваться;  
4) на экране Обучение->Предметы выбрать Вид: по классам и нажать кнопку Добавить, чтобы попасть на страницу Связать предмет и класс.  

Замещение преподавателей
Следует различать преподавателей для предмета в классе:
·"Основные" преподаватели - те, которые назначены для преподавания на экране Обучение->Предметы. Эти преподаватели могут в любой день выставлять отметки в Классном журнале, назначать домашние задания, назначать новые задания по электронным учебным курсам на странице список заданий по учебному курсу и т.д.  
·Замещающие преподаватели - те, которые выбраны вместо "основных" преподавателей на экране Расписание->Составить расписание, при замене в случае болезни, командировки и т.п. (В личной карточке замещающего учителя, в строке Преподаваемые предметы должен быть отмечен предмет, по которому происходит замещение.) Эти преподаватели имеют право выставлять отметки и назначать задания только в те дни, на которые была сделана замена в расписании.
