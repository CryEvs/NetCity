Просмотр доски объявлений

Кто может смотреть и отправлять сообщения на доску объявлений
Доска объявлений - это общедоступный источник внутришкольной информации для всех участников образовательного процесса. Поэтому просматривать сообщения на доске объявлений, по умолчанию, могут все пользователи системы "Сетевой Город", независимо от их роли.
Создавать новые сообщения могут только пользователи-сотрудники. Для этого у них должно быть отмечено право доступа Создавать объявления.

Объявления можно создавать как общие для всех, так и для отдельных групп пользователей. Например, только для пользователей с ролью родителя, только для пользователей с ролью ученика и т.п. В тексте объявлений возможно форматирование, вставка ссылок на локальные и сетевые ресурсы. Подробнее см. Размещение объявлений.

Редактирование объявлений
Чтобы отредактировать объявление, нажмите пиктограмму карандаша рядом с датой размещения объявления.

Удаление объявлений
При создании объявления можно указать дату, при наступлении которой будет объявление автоматически удалено из системы.
Или, чтобы удалить объявление вручную, поставьте "галочку" рядом с датой размещения объявления, затем нажмите кнопку Удалить.

Кто имеет право редактировать и удалять объявления?
Отредактировать сообщение на доске объявлений или удалить его может автор этого объявления, а также сотрудник с ролью администратора системы.
