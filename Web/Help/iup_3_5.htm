Задание предельной нагрузки по ИУП

Откройте экран Планирование -> Нагрузка. В секции «Предельные нагрузки ИУП» требуется задать нагрузку для нужных параллелей. Впишите необходимое значение и нажмите кнопку Сохранить в нижней половине экрана:


Модель ИУП включает предметы различного типа: обязательные предметы (из федерального и регионального компонентов), предметы по выбору (из федерального и регионального компонентов), элективные курсы и т.д. Чтобы компонент стал доступен в таблице ИУП, нажмите кнопку Добавить в секции «Предельные нагрузки ИУП», затем задайте нагрузку по этому компоненту:


Разумеется, вы можете использовать не все компоненты из списка, а лишь необходимые.
