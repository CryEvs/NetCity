Как отправить объявление нужным пользователям
На этом экране вы можете:
·опубликовать объявление для всех пользователей в вашей школе: для этого отметьте галочкой пункт "Все";  
·опубликовать объявление только для отдельных групп пользователей в вашей школе: для этого отметьте галочками те роли пользователей, для которых предназначено ваше объявление. Можно отметить две и более роли (например, сделать объявление доступным для всех учителей и всех родителей).  

Что означает "Удалить это сообщение после:"
Публикуя своё объявление, вы можете задать дату, при наступлении которой оно будет автоматически удалено с доски объявлений.

Форматирование объявления
В поле Сообщение можно ввести текст с форматированием. Например, с выделением цветом, выравниванием, оформлением списка, вставкой изображения или гиперссылки. Для этого используйте соответствующие кнопки на специальной панели.

Какими правами доступа надо обладать, чтобы создавать новые объявления
Создавать новые объявления могут только сотрудники школы, причём у которых отмечено право доступа Создавать объявления. По умолчанию, таким правом доступа обладают все сотрудники.

Как присоединить файл к объявлению
Для того чтобы присоединить файл к объявлению, нажмите кнопку Присоединить файл, в открывшемся экране укажите путь к файлу, введите, если нужно, комментарии, и нажмите кнопку Сохранить. Максимальный размер файла в данном случае - 8 Мбайт. Подробнее об ограничениях на размер присоединяемых файлов в системе
