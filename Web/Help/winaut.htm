Вход пользователей с использованием учетной записи Windows
Возможен упрощенный вход в "Сетевой Город", когда локальная сеть учебного заведения построена на основе домена Windows. В этом случае каждый пользователь уже имеет индивидуальное имя для входа в сеть - учётную запись Windows. Можно настроить систему "Сетевой Город" так, что при входе в неё пароль запрашиваться не будет.

Внимание: автоматический вход в систему возможен только при условиях:
1) компьютер пользователя имеет операционную систему Windows;  
2) пользователь входит в сеть на основе домена Windows;  
3) сервер системы "Сетевой Город" сам является членом домена Windows.  
Во всех других случаях для входа в систему "Сетевой Город" требуется каждый раз набирать имя и пароль.

Как настроить автоматический вход с учетной записью Windows
Настроить автоматический вход с учетной записью Windows можно следующим образом:
1) Пользователь с ролью администратора, войдя в систему "Сетевой Город" в обычном режиме, должен войти на экран Управление -> Настройки школы. По умолчанию, механизм Windows-аутентификации отключен. Нужно установить настройку Windows-аутентификация в положение Включена и нажать кнопку Сохранить. Данная настройка распространяется на всех пользователей данной школы: сотрудников, учеников, родителей.  
2) Если пользователь уже вошел в сеть Windows с использованием своей учётной записи, то он может входить в систему "Сетевой Город" автоматически. На начальной странице сайта "Сетевого Города" находятся две ссылки:  
- Вход в систему;  
- Вход с учетной записью Windows.  
Чтобы войти в систему автоматически, нужно нажать на ссылку Вход с учётной записью Windows. При первом входе нужно будет ввести ваши имя и пароль в системе "Сетевой Город", которые вы хотите связать с вашей учетной записью Windows, и установить галочку Связать с Вашей учётной записью Windows. При следующих входах в "Сетевой Город" у вас не будут запрашиваться имя и пароль.  

Внимание: Важно понимать, что имя и пароль в системе "Сетевой Город" и учетная запись Windows - разные вещи. Система "Сетевой Город" всего лишь позволяет вам связать их между собой. Если пароль в системе "Сетевой Город" не совпадает с паролем для входа в сеть Windows, вы должны помнить оба пароля!

Как можно изменить привязку пользователя к учётной записи Windows
Привязать пользователя "Сетевого Города" к другой учётной записи Windows можно двумя способами:
1) Пользователь с ролью администратора (или другой пользователь с правом доступа редактирования сведений о пользователях) может войти в сведения об этом пользователе, изменить значение поля Учётная запись Windows и нажать кнопку Сохранить.  
2) Сам пользователь в разделе Персональные настройки может нажать кнопку Связать с вашей учётной записью Windows (может потребоваться подтвердить свои учётные данные в домене Windows). После чего в сведениях об этом пользователе автоматически сохранится текущее значение учётной записи Windows.  

Внимание: значение учётной записи Windows должно быть в стандартном формате: ИМЯ_ДОМЕНА\имя_пользователя, например, SCHOOL87\Ivanov.

Как отключить автоматический вход с учетной записью Windows
Чтобы отключить автоматический вход у конкретного пользователя:
1) Пользователь с ролью администратора (или другой пользователь с правом доступа редактирования сведений о пользователях) должен войти в сведения об этом пользователе, очистить поле Учётная запись Windows и нажать кнопку Сохранить.  
2) Сам пользователь в разделе Персональные настройки может очистить поле Учётная запись Windows и нажать кнопку Сохранить.  
Чтобы отключить автоматический вход у всех пользователей в школе, администратор должен войти в Настройки школы, установить настройку Windows-аутентификация в положение Отключена и нажать кнопку Сохранить.

Что происходит, если истекло время неактивности пользователя в системе "Сетевой Город"
Если у пользователя, который вошел в "Сетевой Город", истекло время неактивности и сеанс работы завершился, то система не будет запрашивать у него имя и пароль. В этом случае пользователь войдет в систему "Сетевой Город" автоматически.

Как при включенной Windows-аутентификации один человек может входить в систему "Сетевой Город" от имени разных пользователей
Если пользователь входил в систему "Сетевой Город" автоматически, то после нажатия на кнопку Выход в главном меню он увидит экран Вы вышли из Сетевого Города, на котором:
- кнопка Войти в систему будет вести на обычный (не автоматический) экран входа в систему "Сетевой Город";
- ссылка Войти, используя учетную запись Windows будет вести на автоматический вход в систему "Сетевой Город".
Используя кнопку Войти в систему, можно будет войти пользователем "Сетевого Города" со своим именем и паролем.
