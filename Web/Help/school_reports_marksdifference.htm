Расхождение между средней оценкой и итоговой оценкой

Данный отчёт позволяет обнаружить ошибки при выставлении итоговых отметок.
Отчёт выводит учащихся и предметы, для которых расхождение между средней оценкой и итоговой оценкой больше или равно указанного в фильтре значения (в обе стороны). Например, расхождение >= 0,5.

Получить отчет можно как по всем предметам в одном классе, так и по всем классам для одного и того же предмета. Фильтр Класс позволяет выбрать класс, по которому будет сформирован отчет о расхождении между средней оценкой и итоговой оценкой всех аттестованных в классе учащихся. Фильтр Предмет позволяет выбрать предмет, по которому будет сформирован отчет.

Если в фильтре Класс выбрано конкретное значение класса, то фильтр Предмет показывает предметы из выбранного класса.
Если в фильтре Класс выбрано значение "Все", то фильтр Предмет не зависит от фильтра Класс.

Примечание: Анализируются только те учащиеся, у которых выставлена итоговая оценка и в выбранном учебном периоде существуют текущие отметки.
