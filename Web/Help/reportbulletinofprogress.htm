Сводная ведомость учета успеваемости

Отчет "Сводная ведомость учета успеваемости"

Данный отчёт повторяет итоговую ведомость, которая находится в конце бумажного классного журнала.

Этот отчет предназначен для классных руководителей и завучей. В отчете представлены все оценки учеников по всем учебным периодам, а также годовая оценка, экзаменационная (если был экзамен) и итоговая.
Замечание. В классе может быть задано несколько типов экзаменов (например, устный, письменный, ОГЭ, ЕГЭ и др.), в этом случае в данном отчёте выводятся полные названия экзаменов. Типы экзаменов и названия экзаменов задаются в интерфейсе Администратора сервера СГО в экране "Справочники".

Как изменить порядок следования предметов в данном отчёте?

Советы по распечатке данного отчёта:
Выгрузите данный отчёт в табличный редактор Microsoft Excel (или OpenOffice Calc), после чего:
1. Отформатируйте названия предметов так, чтобы они располагались по вертикали.  
2. Заполните графу "Решение педсовета" (данная графа не заполняется автоматически).  
3. Распечатайте отчёт средствами вашего табличного редактора.
