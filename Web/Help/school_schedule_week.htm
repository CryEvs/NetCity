Расписание на неделю

Виды расписания на неделю
В графе Вид выберите удобный вид расписания из тех, которые описаны ниже.

Расписание по дням недели  
Данный вид расписания удобен, если для просмотра выбран один класс.  
Строки таблицы выводят последовательно уроки (первый урок, второй урок...). Столбцы таблицы соответствуют разным дням недели.  
 
Расписание по классам  
Данный вид расписания позволяет наглядно вывести расписание нескольких классов.  
Здесь в каждом столбце таблицы выводится свой класс из указанного диапазона.  
 
Расписание по учителям  
Данный вид расписания выводит график работы учителей, в т.ч. позволяет увидеть занятость и "окна" учителей.  
(Этот вид расписания есть только для сотрудников школы, у которых отмечено право доступа Просматривать расписание для всех классов).  

Вы можете просматривать расписание согласно вашим правам доступа. Например, если вы учитель, то, как правило, можете видеть расписание только:
·в тех классах, где вы являетесь классным руководителем;  
·по тем предметам, которые вы преподаёте, а также по которым замещали занятия других учителей.  

Расписание для ученика и родителя
Если вы ученик или родитель, то расписание будет доступно только в режиме просмотра.
Если у родителя обучается в школе двое и более детей, то можно выбрать нужного ребёнка в поле Ученик.

Дополнительные возможности
С помощью фильтра Класс можно выбрать конкретный класс или диапазон классов.
Если нужно ограничить просмотр, вы можете использовать фильтры Учитель, Предмет, Вид деятельности (Учебная/Внеурочная).

Если в вашей школе есть несколько вариантов расписания звонков, то дополнительно можно выбрать Вариант. Если есть несколько смен, то можно выбрать Смену.

Если вам нужно быстро попасть в расписание на какой-то конкретный день, то нажмите на название дня недели.
Если вы сотрудник школы, имеющий право доступа Составлять расписание и определять список кабинетов ОО, то вы можете щёлкнуть в ячейку таблицы, где выводится класс и предмет, - чтобы быстро перейти к редактированию расписания в данный день в данном классе.

Расписание для ИУП-классов
Если в вашей школе есть классы с типом учебного плана "Индивидуальный", то в фильтре Класс они будут доступны для выбора только в случае, если в этих классах есть ученики.

Печать расписания
Любой вид недельного расписания вы можете просмотреть в удобном для печати виде, нажав кнопку На печать. В новом открывшемся окне браузера нажмите кнопку Печать (Print). Кроме того, есть возможность экспорта расписания в таблицу формата MS Excel. Подробнее об этой возможности вы можете прочитать на странице Экспорт данных из системы "Сетевой Город".
