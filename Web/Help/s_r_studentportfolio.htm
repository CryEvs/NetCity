Контроль ведения портфолио учащихся

Данный отчёт выводит сводную информацию (по каждому классу и по школе) о заполнении личных портфолио учащихся и итогов участия в мероприятиях.

Блок "Количество учащихся с заполненными разделами"
В этом блоке выводится сводная информация о проценте заполнения разделов личного портфолио учащегося с файлами/ссылками:
·Портрет  
·Достижения  
·Коллектор  
·Рабочие материалы  
Для каждого из разделов отчёт считает, что он заполнен, если в этом разделе прикреплён хотя бы один файл или создана хотя бы одна гиперссылка.

В подграфе "Итоги участия в мероприятиях" выводится количество детей, которые являются участниками мероприятий с заполненным полем "Итог".

Блок "Заполнен хотя бы один раздел"
В этом блоке выводится количество детей, у которых заполнен ЛЮБОЙ раздел портфолио (не обязательно из четырёх перечисленных выше), либо которые имеют хотя бы один итог участия в мероприятии.

Количество учащихся подсчитывается на текущую дату. (Если же отчёт формируется по закрытому учебному году, то формируется на дату окончания учебного года.)
