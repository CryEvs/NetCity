Создание/Редактирование документа
Для добавления в хранилище или для редактирования документа, укажите к нему путь, введите название и краткое описание. Затем нажмите кнопку Сохранить. После этого документ будет доступен на экране Хранилище школьных документов для всех сотрудников школы.

Если выбран тип Публичные документы, то действует следующее ограничение:
в раздел "Информация о порядке проведения государственной (итоговой) аттестации" можно прикрепить только файл с расширением HTM, HTML или TXT, потому что из этого раздела информация должна выгружаться на Портал государственных услуг в определённом формате.
