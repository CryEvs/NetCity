Отчёты дошкольных организаций

Здесь описаны отчёты, которые доступны на экране "Отчёты" только для дошкольных образовательных организаций.

Подраздел "Родительская плата"

В отчётах подраздела «Родительская плата» используются нормативы родительской платы. Норматив – это сумма за один день посещения ребёнком ДОО. На уровне Управления образования определяется справочник нормативов для различных категорий детей (например, могут быть заданы разные нормативы для детей из многодетных семей, детей с ОВЗ, часто болеющих детей и др.). На уровне ДОО из этого справочника для каждого ребёнка выбирается персональный норматив на каждый месяц.

На уровне Управления образования для норматива можно задать признак "Для дней непосещения". Это даёт возможность вводить для ребёнка и количество дней посещения, и количество дней непосещения и, соответственно, учитывать их при расчёте родительской платы.

На уровне Управления образования можно задать изменение норматива родительской платы, причём изменение норматива может вступать в силу со следующего месяца. По этой причине один из фильтров в отчётах по родительской плате – это фильтр «Месяц», от выбранного в нём месяца зависят нормативы для расчёта.
