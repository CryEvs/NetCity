Отмена занятий

На практике бывает, что расписание было составлено заранее, например, на будущую четверть или полугодие, а затем возникла необходимость в отмене занятий (из-за непогоды, массового мероприятия, поездок, ошибочного назначения на праздничный день и т.п.).

Экран "Отмена занятий" позволяет очистить расписание (отменить занятия) на определённый день, причём как для некоторых классов, так и для всей школы сразу.

Если нужно вместо отмены занятий перенести их на другой день, используйте другой экран - "Перенос дней" (действует только для всей школы, а не для отдельных классов).

Внимательно читайте диагностические сообщения системы. Восстановить удалённую информацию будет нельзя!

Выберите дату, за которую нужно очистить расписание, укажите список классов и нажмите кнопку Удалить занятия. После этого система проверит, есть ли у выбранного (-ых) класса (-ов) в этот день:
·оценки,  
·посещаемость,  
·задания,  
·связанные темы уроков из КТП  
- и обязательно выдаст запрос, удалять ли у выбранного (-ых) класса (-ов) такую информацию в этот день.

Проверки проходят последовательно для выбранных классов.

Если пользователь отвечает "Нет", то проверки прерываются, при этом никакая информация не удаляется (в том числе для предыдущих классов).
Если пользователь отвечает "Да", то информация по данному классу всё равно не будет удалена, пока не завершены проверки для всех классов.

Другими словами: если вы передумали удалять данные, не завершив проверки для всех классов, то нужно нажать кнопку "Нет" при очередном предупреждении, при этом никакая информация удалена не будет. Если же на каждый вопрос вы ответили "Да", то после всех проверок удаляется вся указанная информация.

После проверки наличия связанных данных, система удаляет само расписание занятий в данный день в выбранных классах.
