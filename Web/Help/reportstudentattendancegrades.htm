Отчет "Итоги успеваемости и качества знаний ученика"
Данный отчет дает возможность увидеть результаты, которых добился ученик в процессе обучения по сравнению с другими учениками своего класса, а также по сравнению с учениками из параллельных классов. Он выводится в простой и наглядной графической форме, где три столбца гистограммы для каждого месяца представляют собой процент качества знаний самого учащегося, средний процент по классу и средний по параллели. Формулу, по которой рассчитывается процент качества знаний, вы можете посмотреть Формулы показателей успеваемости.

Примечание: Данный отчет рассчитан на 5-балльную шкалу оценок.
