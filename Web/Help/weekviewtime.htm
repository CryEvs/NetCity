Расписание школы по дням недели

Виды расписания на неделю
На экране "Неделя" вы можете самостоятельно выбрать вид расписания, который вам в данный момент наиболее удобен. Это может быть расписание по дням недели, расписание для класса или предмета, расписание по учителям. Последний вид доступен только тем пользователям, у которых отмечено право доступа Просматривать расписание для всех классов.

Когда удобно использовать расписание по дням недели
Расписание по дням недели составлено так, чтобы вы быстро могли увидеть какие классы, когда занимаются и в каких кабинетах в определенный день. Указать конкретный класс или диапазон классов можно с помощью фильтра Класс. Это может помочь увидеть излишнюю нагрузку на учащихся в один день при малом количестве уроков в другой день, т.е. сделать расписание более сбалансированным.

"Окна" между уроками
Подобный вид расписания позволит вам легко отследить наличие "окон" у классов и оценить общее количество уроков за неделю или за каждый день в отдельности.

Печать расписания
Любой вид недельного расписания вы можете просмотреть в удобном для печати виде, нажав кнопку . Для вывода на печать в новом открывшемся окне браузера нажмите кнопку Печать (Print). Кроме того, есть возможность экспорта расписания в таблицу формата MS Excel с помощью кнопки . Подробнее об этой возможности вы можете прочитать на странице Экспорт данных из системы "Сетевой Город".
