Мастер ввода данных


Мастер ввода данных – простой пошаговый инструмент ("Wizard"), облегчающий первоначальный ввод данных сразу после установки системы. Мастер ввода данных запускается администратором системы, который имеет имя пользователя "admin". Цели прохождения "Мастера":
·за короткое время ввести основные административные данные, без которых работа в "Сетевом Городе" невозможна;  
·подготовить базу данных "Сетевого Города" для доступа других сотрудников школы, учеников и родителей.  
Мастер ввода данных состоит из 10 шагов.
