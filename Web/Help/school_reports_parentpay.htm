Родительская плата и посещаемость

Уровень отчёта: только ДОО

Данный отчёт выводит для каждого ребёнка всю информацию о родительской плате по месяцам, за текущий учебный год. Это информация из экрана "Журнал->Родительская плата" в виде, более удобном для печати.

Можно вывести данный отчёт только по одному выбранному воспитаннику, либо по всем воспитанникам группы (отчёт, распечатанный по всем воспитанникам, удобно разрезать ножницами для раздачи родителям).
