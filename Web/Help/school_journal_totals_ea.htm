Итоговые отметки

По программам внеурочной деятельности можно выставлять:
·итоговые отметки за четверть/триместр/полугодие, причём только по системе "зачёт/незачёт";  
·отметки за год, причём только по системе "зачёт/незачёт".  

Экзамены по программам ВД не предусмотрено, поэтому отметки за экзамены и итоги года не выставляются.
