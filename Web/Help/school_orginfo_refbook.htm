Справочники
Справочник - это список, который может редактироваться пользователем-администратором. На данном экране представлены два справочника на уровне школы:
·Подразделения школы  
·Виды помощи школе  

При создании школы эти справочники заполняются по умолчанию. В процессе дальнейшей работы их можно отредактировать с помощью кнопок Добавить и Удалить.

Где используются данные справочников
Данные справочников используются в личных карточках пользователей в разделе Пользователи пункта меню Управление. Справочник Подразделение предназначен для карточек пользователей-сотрудников (администратор, завуч, учитель и др.), а справочник Помощь школе - для карточек родителей.

Какие ещё справочники есть в системе
Специальный пользователь Администратор сервера "Сетевого Города" может редактировать ещё целый ряд справочников, например:
·Типы экзаменов (используется при выставлении оценок за экзамены),  
·Гражданство (используется в личных карточках пользователей),  
·Общие предметы (используется при получении отчётов по предметам),  
·Иностранные языки (используется в личных карточках учащихся),  
·Должность (используется в личных карточках сотрудников),  
·Причины выбытия (используется при создании приказов о выбытии учащихся),  
и др.
