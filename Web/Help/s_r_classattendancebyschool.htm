Сводный отчёт о посещаемости по ОДО

Данный отчёт подсчитывает общее количество человеко-часов в каждой группе ОДО, которые учитываются как проведённые (посещённые детьми).
Таким образом, можно рассчитать выполнение муниципального задания по реализации дополнительных общеобразовательных общеразвивающих программ.

Отчёт выводит по столбцам все месяцы (в пределах текущего учебного года). В каждой ячейке отчёта подсчитано количество фактически посещённых человеко-часов в каждом объединении (из журнала посещаемости).

Формула расчёта количества часов
(Количество фактически посещённых человеко-часов в объединении за месяц) = (Количество человеко-часов в объединении за месяц по расписанию) - (Количество пропусков детей за месяц).  

Также выводятся итоговые суммарные строки по каждой направленности.
