Решения комиссий

Поле "Решения комиссий" в личной карточке ученика позволяет сформировать сводную таблицу для ученика по решениям следующих комиссий:

Для общеобразовательной организации:
·решение ПМПК (психолого-медико-педагогическая комиссия),  
·решение МСЭ (медико-социальная экспертиза),  
·решение ВК (врачебная комиссия).  

Для дошкольной образовательной организации:
·решение ПМПК (психолого-медико-педагогическая комиссия),  
·решение МСЭ (медико-социальная экспертиза),  
·вид льготного содержания.  
 
Кнопка Добавить позволяет добавить информацию по новому решению комиссии. Чтобы отредактировать уже внесённое решение, нажмите гиперссылку в графе "Тип комиссии".

Чтобы получить информацию не по одному ученику, а сразу по всем учащимся школы/детсада, для которых указаны решения комиссий, используйте отчёт "Информация о детях, имеющих рекомендации ПМПК на обучение".

Особенность поля "Решения комиссий": при переводе учащегося/воспитанника в другую образовательную организацию, данное поле будет доступно для редактирования.
