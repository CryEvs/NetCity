Данные для ЕГЭ

Этот экран системы "Сетевой Город" позволяет автоматически получить списки учащихся, сдающих ЕГЭ, в формате программы RCMCSVConsole, чтобы отправить эту информацию в Региональный Центр обработки информации (РЦОИ) и далее в Федеральный центр тестирования.
Формат экспорта соответствует формату программы RCMCSVConsole от 2009 г.

Порядок действий для экспорта данных в формат ЕГЭ

1. Установить программу RCMCSVConsole, скопировать в ее рабочую папку 4 файла, которые присланы из РЦОИ:
NN_***_Areas.cs_  
NN_***_Governments.cs_  
NN_***_Participants.cs_  
NN_***_Schools.cs_,  
где NN – это двузначный код региона, *** – это код вашего ОУ.
При этом файл NN_***_Participants.cs_ (данные об участниках ЕГЭ) – должен быть пустым, он предназначен для заполнения при помощи программы RCMCSVConsole. "Сетевой Город" сможет заполнить этот файл автоматически.

2. Если требуется отредактировать информацию об ОУ (наименование, вид, тип, адрес, Ф.И.О. руководителя и др.), то можно сделать это при помощи программы RCMCSVConsole.

3. В "Сетевом Городе" выполнить следующие действия:
·у всех учащихся, сдающих ЕГЭ, должен быть указан класс, и нужно заполнить поля:  
·Предметы для ЕГЭ (выбранные предметы для сдачи экзамена);  
·Тип документа для ЕГЭ (паспорт, или свидетельство о рождении, или другой документ). Если для учащегося указан тип документа, отличный от паспорта или свидетельства о рождении, то надо ввести номер документа в поле «Номер паспорта»;  
·Тип ограничения возможностей здоровья;  
·Предметы для ЕГЭ по сокр.программе.  
·на экране Данные для ЕГЭ заполнить поле Код образовательного учреждения (требуется ввести 6-значное число);  
·в поле Файл с информацией об ОУ указать местонахождение файла NN_***_Schools.cs_ , который получен из РЦОИ;  
·нажать кнопку Экспорт в формат ЕГЭ, после чего "Сетевой Город" сохранит файл NN_***_Participants.cs_ , причем для его сохранения нужно указать ту же папку, где находится файл NN_***_Schools.cs_.  
Важно отметить, что система "Сетевой Город" автоматически включит в файл всех учащихся, у которых заполнено поле Предметы для ЕГЭ. Это могут быть учащиеся не только выпускного класса, но и других классов. Будет выведена статистика о количестве экспортированных записей.

4. Полученные 4 файла (.cs_) отправить в РЦОИ.
