Быстрый ввод новых учеников


"Быстрый ввод" позволяет ввести только самые основные сведения о новых учениках. Таким способом удобно добавлять одного или нескольких новых учащихся в систему.

Впоследствии вы сможете дополнить любые поля в личной карточке учащегося, если на экране "Ученики" щёлкнете на фамилию ученика.

Обязательные для заполнения поля обозначены звездочками ***:
·Фамилия  
·Имя  
·Дата рождения  
·Пол  
·Имя пользователя  
·Пароль  
·Подтверждение (пароля)  

Внимательно выбирайте Класс в выпадающем списке: ученики сразу будут зачислены в этот класс.

Для сохранения обязательно нажмите кнопку Сохранить. Однако не обязательно сохранять каждую запись по отдельности. Вы можете с помощью кнопки Добавить/Обновить заполнить список до 10 учеников, а после этого одним нажатием кнопки Сохранить отправить данные в систему.

Если ввести здесь родителей вместе с учениками, какие будут у них логины и пароли?
При быстром вводе учащихся есть возможность ввести и данные о родителях, в этом случае у родителей будут логины вида:
оИванов (для отца),
мИванова (для матери),
а пароль будет совпадать с фамилией (Иванов).
