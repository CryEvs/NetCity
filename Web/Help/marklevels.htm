Уровни отметок для 10- и 12-балльной шкалы

Система "Сетевой Город. Образование" поддерживает работу не только с 5-балльной, но и с другими шкалами отметок. Большинство отчётов по успеваемости гибко подстраивается под шкалу отметок.

В ряде отчётов используется приведение к уровням "отлично", "хорошо", "удовлетворительно", "неудовлетворительно". Это следующие отчёты:
·Сводный отчёт об успеваемости по школе;  
·Сводный отчёт об успеваемости и качестве обучения по школе;  
·Итоги успеваемости по предмету за учебный период;  
·Отчёт учителя-предметника.  

Для 10-балльной системы используется следующая фиксированная шкала перевода:
·1-4 балла - неудовлетворительно,  
·5-6 баллов - удовлетворительно,  
·7-8 баллов - хорошо,  
·9-10 баллов - отлично.  

Для 12-балльной системы используется следующая фиксированная шкала перевода:
·1-3 балла - неудовлетворительно,  
·4-6 баллов - удовлетворительно,  
·7-9 баллов - хорошо,  
·10-12 баллов - отлично.
