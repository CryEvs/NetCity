Печать аттестатов

Система "Сетевой Город. Образование" интегрирована с программой печати аттестатов «ИвАттестат», версия 2.0.1 (май 2014 г.), разработка Управления образования администрации г. Иваново:
http://www.ivedu.ru/infusions/pro_download_panel/download.php?did=34

"Сетевой Город" позволяет автоматически получить файл .csv, который можно загрузить в программу «ИвАттестат».

Какие данные автоматически выгружаются из "Сетевого Города" в файл .csv?
В аттестате для 9 и 11(12) классов различаются списки предметов, поэтому выгружаются по отдельности:
·список учащихся 9-х классов;  
·список учащихся 11(12)-х классов.  

В фильтре "Параллель" можно выбрать для выгрузки любую параллель, начиная с 9-й и выше, для которой был составлен учебный план.

Для каждого учащегося в файл .csv выгружаются:
·ФИО в именительном падеже,  
·дата рождения,  
·список предметов с итоговыми отметками (тип отметки «Итог»).  
Однако, этой информации недостаточно, чтобы распечатать аттестат. Часть информации не хранится в "Сетевом Городе". В программе «ИвАттестат» дополнительно нужно будет ввести для каждого учащегося:
·ФИО в дательном падеже,  
·серию и номер аттестата.  

Какая отметка рассматривается в качестве итоговой для аттестата?
Если по предмету проводился экзамен, то в классном журнале выделяют столбцы «Год» (отметки у всех учеников), «Экзамен» (для тех, которые сдавали) и «Итог» (для тех, которые сдавали). При выгрузке данных для аттестата принимается правило: если у ученика по данному предмету нет отметки типа «Итог», то выводится отметка из графы «Год».
Для 9-классников берётся отметка за 9-й класс; для 11-классников, соответственно, отметка за 11-й класс.

В случае, если по некоторым предметам задана система "зачёт-незачёт", вместо оценки "зачёт" передаётся "5", а оценка "незачёт" не передаётся для печати аттестата. Подробнее о системе "зачёт-незачёт"...

Для чего предназначен экран "Выбор предметов для печати аттестатов"?
Данный экран позволяет подготовить список предметов, по которым будут выгружены отметки в программу «ИвАттестат».

Как правило, названия предметов и порядок следования в аттестате совпадают с учебным планом. Однако, кроме отметки за последний год обучения, в аттестат выставляются отметки по предметам, которые закончились раньше, например, для 11-го закончились в 10-м классе, а в аттестаты 9-классников выставляют отметки по предметам, которые закончились в 6-7 классах (например, музыка, ИЗО и др.).

Средствами программы «ИвАттестат» (версия 2.0.1) передвигать предметы, вставлять между ними новые предметы нельзя. В «ИвАттестат» можно только добавлять предметы в конец списка. Однако, в аттестате предметы должны следовать в определенном порядке: например, краеведение после географии, а ИЗО, музыка перед МХК. Поэтому данный экран позволяет максимально подготовить список предметов в системе "Сетевой Город. Образование" перед выгрузкой в программу «ИвАттестат».

Список предметов выводится в порядке следования в учебном плане, с указанием, в какую часть он должен пойти – в основную часть аттестата или в раздел «Дополнительные сведения». В каждом из двух списков есть возможности:
·перемещать предметы вверх-вниз ("перетаскиванием" мышью);  
·добавлять новые названия предметов в список;  
·удалять предметы из списка.  

Списки предметов могут быть разными для классов разных профилей в одной параллели (например, естествознание для общеобразовательных классов, но физика, химия, биология для профильных и т.п.). Если в разных классах списки предметов различаются, то сформируйте объединённый список предметов. В программе «ИвАттестат» для конкретного учащегося в аттестат будут выводиться только те предметы, за которые он имеет отметку.

"Дополнительные сведения" в программе «ИвАттестат» будут заполнены одинаково для всех учащихся, вне зависимости от присутствия оценки.

После нажатия кнопки Экспорт файла для «ИвАттестат» будет сохранён файл с расширением .CS_. Этот файл необходимо переименовать в .CSV, после чего импортировать в программу «ИвАттестат».
