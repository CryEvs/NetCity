Форма № ОШ-9. Титульный лист
Форма № ОШ-9 предоставляет сведения о допрофессиональной и профессиональной подготовке обучающихся 8-11 (12) классов в дневном общеобразовательном учреждении. На титульном листе Формы № ОШ-9 указываются Наименование отчитывающейся организации, код по ОКПО, код по ОКАТО и код по ОКОГУ.
Сверху и снизу на титульном листе есть ссылки на другие пункты Формы № ОШ-9. Для перехода на них нажмите на соответствующую ссылку левой кнопкой мыши: Титульный лист : пп.1-2

В ОШ-9 сведения о составе школы автоматически подсчитываются на начало текущего учебного года (как указано в титульном листе).

Пример: сейчас идет 2007-2008 учебный год, в формах ОШ будет авторасчёт данных по состоянию на 5 сентября 2007 г.

Печать Формы № ОШ-9
Если титульный лист готов, то его можно распечатать. Для этого нажмите кнопку Для печати. В новом открывшемся окне броузера нажмите кнопку Печать (Print). Таким же способом вы можете распечатать все остальные листы отчета.
Форма № ОШ-9 заполняется один раз в год, подписывается руководителем общеобразовательного учреждения и должностным лицом, ответственным за заполнение формы, с указанием номера контактного телефона и даты заполнения, и сдается 7 октября.

Примечание: Чтобы Форма № ОШ-9 была доступна и в следующем учебном году, ее надо закрыть с помощью соответствующей кнопки.
