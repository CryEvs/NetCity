Типы экзаменов

На данном экране можно задать типы экзаменов, которые проводятся в данном классе по данному предмету. Чтобы выставлять экзаменационные отметки, нужно выбрать по меньшей мере один тип экзамена: поставить галочку в графе "Использовать". Если выбрано больше одного типа экзамена (например, "Устный экзамен" и "ЕГЭ"), то в отчёты по итоговым отметкам войдут все выбранные типы экзаменов.

Список возможных типов экзаменов может быть изменён Администратором сервера системы "Сетевой Город" (экран Справочники -> Типы экзаменов в интерфейсе Администратора сервера).

Запись "Используется" в графе "Использовать" говорит о том, что в данном классе по данному предмету у учащихся есть выставленные отметки за этот тип экзамена.

Что означает графа "По выбору"?
В графе "По выбору" нужно поставить галочку для экзаменов по тем предметам, которые учащиеся сдают по выбору. Это нужно для того, чтобы в отчётах о выставлении итоговых отметок те учащиеся, которые не сдавали экзамен по выбору по данному предмету, не учитывались как не получившие отметку.

Выставление отметок по ЕГЭ
Для экзамена типа "ЕГЭ" можно выставить отметку только по 100-балльной шкале. При этом для всех остальных отметок в школе может использоваться 5-балльная или любая другая шкала, в том числе "зачёт-незачёт". Система оценивания для экзаменов также задаётся в экране Справочники -> Типы экзаменов в интерфейсе Администратора сервера.

Если есть необходимость выставить отметки за ЕГЭ по другой шкале (например, по 5-балльной), рекомендуется для этого добавить в справочник "Типы экзаменов" ещё одно значение (например, "ЕГЭ по 5-балл.шкале").

Какие отчёты в "Сетевом Городе" отображают результаты экзаменов?
Результаты экзаменов можно проанализировать с помощью отчётов:
·Распечатка классного журнала  
·Сводная ведомость учёта успеваемости  
·Отчёт учителя-предметника (в данном отчёте не выводятся отметки по ЕГЭ)  
·Итоги успеваемости класса за учебный период  
·Табель успеваемости ученика
