Доступ классного руководителя

Классный руководитель в системе "Сетевой Город" - это пользователь с ролью "Учитель", который указан в экране "Классы" в графе "Классный руководитель" для какого-либо класса.

Классный руководитель автоматически получает доступ к данным "своего" класса в соответствии с установленными правами доступа. По умолчанию права доступа установлены так, чтобы классный руководитель имел возможность в своём классе:
·редактировать имена пользователей и пароли учеников и родителей;  
·редактировать сведения об учениках и родителях;  
·просматривать расписание;  
·выставлять отметки в классный журнал и назначать домашние задания (причём по всем предметам);  
·назначать задания учащимся по электронным учебным курсам;  
·выставлять итоговые отметки за учебные периоды;  
·просматривать отчёты об успеваемости и посещаемости;  
·рассылать почтовые сообщения и SMS-сообщения учащимся и родителям;  
·рассылать отчёты по успеваемости учащимся и родителям.  

Пользователь с ролью "Администратор системы" может изменить данные права доступа.

Если класс имеет признак "Учебный план=Индивидуальный", то функции классного руководителя сужаются, поскольку в такой класс могут быть зачислены ученики из других классов и даже других параллелей. По этой причине на экранах:
·Журнал -> Классный журнал;  
·Журнал -> Итоговые отметки;  
·Журнал -> Темы уроков и задания  
- доступ классного руководителя ограничен только просмотром информации. (Речь только о классе, который работает по ИУП.)
