Программы дополнительного образования

Этот экран доступен только в организациях дополнительного образования (ОДО).

Каждое объединение в ОДО создаётся на основе определённой программы дополнительного образования, список которых определяет сама организация. На этом экране выводится список всех программ, созданных в вашей ОДО.

Кнопка Добавить позволяет добавить новую программу в список.
Чтобы заполнить сведения для уже введённой программы, щёлкните по названию нужной программы.

Некоторые свойства программы дополнительного образования
Любая программа имеет направленность, которая должна быть выбрана из следующего списка:
·Техническая  
·Естественнонаучная  
·Физкультурно-спортивная  
·Художественная  
·Туристско-краеведческая  
·Социально-гуманитарная  

Поле "Вид деятельности" позволяет уточнить вид спорта или искусства для программы; возможные значения определяются направленностью программы.

Статус программы
Для программы можно выбрать статус из следующего списка:
·Активная программа  
·Черновик  
·Архивная программа  
·Программа, подготовленная к публикации педагогами  
Если программа больше не используется в вашей ОДО, то рекомендуется присвоить ей статус "Архивная".

Статус удобно использовать для отображения списка программ: по умолчанию выводятся только активные программы. Кроме того, можно создавать новые объединения только на основе активных программ.
В остальном в системе не ограничиваются возможности работы с архивными программами (например, можно зачислять учащихся в объединения, созданные на основе архивной программы).

После перехода на следующий учебный год, нужно ли вводить список программ заново?
Нет, это необязательно. После формирования нового учебного года, в списке программ в вашей ОДО будут отображаться программы предыдущих учебных годов. Нужно только проверить и уточнить свойства программ.
Обратите внимание на группу полей "Часов по программе, в том числе": для одной и той же программы в разных учебных годах эти нагрузки могут быть разными.
