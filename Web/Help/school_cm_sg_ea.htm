Группы

Данный экран позволяет вести список групп внеурочной деятельности (ВД). Эти группы не отражаются в обычном классном журнале, но участвуют в журнале ВД и используются при составлении расписания ВД.

Внимание! Группы ВД отличаются от обычных предмето-групп (которые создаются для ведения обычного классного журнала):
1. Группы ВД можно создать без предварительного создания часов в плане внеурочной деятельности.  
2. В группу ВД можно зачислить детей из разных классов, и даже из разных параллелей. При создании группы ВД нужно выбрать параллели, из которых вы будете зачислять учеников в эту группу.  
3. Для групп ВД используется только система оценивания "Зачёт/незачёт".  

В остальном работа с группами ВД аналогична работе с обычными предмето-группами (которые можно вести в экране Обучение->Предметы).
