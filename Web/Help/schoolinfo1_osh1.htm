Форма № ОШ-1. Титульный лист
Форма № ОШ-1 предоставляет сведения о дневном учебном общеобразовательном учреждении. На титульном листе Формы № ОШ-1 указываются Наименование отчитывающейся организации, код по ОКПО, код по ОКАТО и код по ОКОГУ.
Сверху и снизу на титульном листе есть ссылки на другие пункты Формы № ОШ-1. Для перехода на них нажмите на соответствующую ссылку левой кнопкой мыши: Титульный лист : пп.1-2 : пп.3-4 : пп.5-7 : пп.8-12 : пп.13-14 : пп.15-16 : п.17

В ОШ-1 сведения о составе школы автоматически подсчитываются на начало текущего учебного года (как указано в титульном листе). Исключение - возрастной состав в п. 5, который дается на 1 января календарного года, соответствующего текущему учебному году.

Пример: сейчас идет 2009-2010 учебный год, в формах ОШ будет авторасчёт данных по состоянию на 20 сентября 2009 г., а п.5 в ОШ-1 (возрастной состав) – по состоянию на 1 января 2010 г.


Печать Формы № ОШ-1
Если титульный лист готов, то его можно распечатать. Для этого нажмите кнопку Для печати. В новом открывшемся окне броузера нажмите кнопку Печать (Print). Таким же способом вы можете распечатать все остальные листы отчета.
Форма № ОШ-1 заполняется один раз в год, подписывается руководителем общеобразовательного учреждения и должностным лицом, ответственным за заполнение формы, с указанием номера контактного телефона и даты заполнения, и сдается 7 сентября.

Примечание: Чтобы Форма № ОШ-1 была доступна и в следующем учебном году, ее надо закрыть с помощью соответствующей кнопки.
