Список участников мероприятия

Данный экран состоит из двух блоков:
·Информация о мероприятии  
Здесь представлено описание мероприятия: дата, тип мероприятия, данные об организаторе и т.д.  
·Список участников  
Здесь выводится собственно список участников с результатами участия (если результаты были введены в систему).  

Блок "Список участников"
В поле "Организация" можно выбрать конкретную организацию, участники из которой вас интересуют. (В вашем школьном мероприятии могут участвовать дети в т.ч. из других школ.)

В поле "Поиск" можно ввести любую часть ФИО ученика (например, только фамилию или только имя), или оставить поле пустым.

По нажатию кнопки Загрузить выводится список участников, которые удовлетворяют условиям поиска.
