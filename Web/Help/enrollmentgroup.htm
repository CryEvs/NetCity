Подгруппы учеников по предметам
На этой странице в виде таблицы представлена информация о распределении учащихся класса по подгруппам.

В системе "Сетевой Город" ученик может быть зачислен одновременно в две и более подгрупп по предмету. При этом действуют следующие правила выставления отметок:

·текущие отметки по предмету можно выставлять в обеих подгруппах по предмету без ограничений,  
·итоговую отметку по предмету можно выставить только одну в данном учебном периоде (т.е. если в одной подгруппе уже выставлена итоговая отметка, то во второй подгруппе этому же ученику выставить итоговую отметку невозможно).
