Импорт списка учеников и родителей
Система "Сетевой Город" позволяет ввести список учеников и родителей из файла формата .xls , который можно получить с помощью Microsoft Excel или OpenOffice Calc. Это очень удобно, если данные об учащихся и их родителях уже существуют в вашей школе в электронном виде. Импорт позволяет заполнить практически все сведения об учениках и родителях. Подробная инструкция доступна по ссылке Как пользоваться импортом.

В процессе импорта (в момент анализа файла и отдельно в момент самого импорта) блокируются все кнопки навигации и пункты меню системы.

Какие логины и пароли будут у учеников и родителей после импорта?
Для каждого ученика и родителя при импорте будет автоматически сформировано имя пользователя (логин) и пароль.
·Логины учеников (родителей) можно увидеть, добавив на экране Управление -> Ученики (Родители) просмотр графы "Имя пользователя" (для этого нажмите кнопку-треугольник справа от кнопки Загрузить).  
·Пароли пользователей увидеть в системе либо распечатать невозможно (из соображений безопасности). Однако есть правило: для каждого пользователя пароль после импорта будет присвоен как Фамилия + 4-значный код (этот код одинаков для всех записей в одном сеансе импорта; код выводится на экран при завершении импорта, его нужно запомнить). Например, если на экран был выведен численный код 8713, то пользователю Сидоров был присвоен пароль Сидоров8713, а пользователю Павлов в том же сеансе импорта - пароль Павлов8713.  
При первом же входе в систему пользователю будет предложено сменить его пароль.

Импорт списка сотрудников
