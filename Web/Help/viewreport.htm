Страница просмотра отчёта

Здесь вы можете получить выбранный вами отчет в виде, удобном для печати. Для этого нажмите кнопку . Чтобы вывести на принтер, в новом открывшемся окне браузера нажмите кнопку Печать (Print).
Можно также экспортировать отчет в таблицу формата MS Excel для дальнейшей работы с ним (например, для каких-либо статистических исследований). Для этого нажмите кнопку . Подробнее об этой возможности вы можете прочитать на странице Экспорт данных из системы "Сетевой Город".
