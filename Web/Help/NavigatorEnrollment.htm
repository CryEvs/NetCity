Зачисление учащихся из Навигатора дополнительного образования детей

В Самарской области работает "Навигатор дополнительного образования детей" - образовательный портал для широкого круга пользователей. На этом портале, в частности, родитель (законный представитель обучающегося) может выбрать организацию дополнительного образования (ОДО), программу дополнительного образования и подать заявку на зачисление.

Порядок действий при зачислении учащегося в ОДО из Навигатора дополнительного образования

  1. Заявка, которую подал родитель на портале, проходит первичную проверку сотрудником ОДО: проверяется заполнение всех необходимых полей в заявке. После одобрения заявка в Навигаторе получает статус "Кандидат на зачисление".
  2. В системе АСУ РСО сотрудник ОДО создаёт приказ о зачислении учащихся в группу (объединение), при этом выбирая источник зачисления "Навигатор дополнительного образования":
  3. Отображается список детей, удовлетворяющих условиям:
    • в Навигаторе есть заявка в данную ОДО,
    • в Навигаторе есть заявка на данную программу,
    • учащийся ещё не зачислен в данную ОДО на данную программу в системе АСУ РСО.
    Важно! Сотрудник должен предварительно выбрать для зачисления группу (объединение), которая имеет ту же самую программу дополнительного образования.
  4. Сотрудник должен выбрать нужных учащихся и нажать кнопку Добавить учеников в приказ. После этого система проводит проверку персональных данных, и сотрудник ОДО должен выбрать, использовать ли имеющиеся в системе записи или создать новые записи.
    Важно! Внимательно читайте сообщения системы, чтобы не допускать появления учащихся-"дублей".
  5. Для каждого учащегося нужно выбрать способ оплаты из следующих вариантов:
    • Бюджет
    • Платно
    • По сертификату,
    а также заполнить поле "Основание для зачисления":
    Важно! Если выбран вариант "По сертификату", то будет автоматически сгенерирован сертификат дополнительного образования для ученика.
    (Если ученик уже имеет сертификат, то будет использован имеющийся.)
  6. После указания способа оплаты все выбранные учащиеся зачисляются в выбранную группу (объединение).
  7. Сотрудник ОДО может увидеть всю информацию о зачислении (в том числе номер и статус сертификата) в личной карточке зачисленного ученика:
  8. Если необходимо, сотрудник ОДО может, щёлкнув по гиперссылке, изменить способ оплаты и основание для зачисления:
  9. Если был указан способ оплаты "По сертификату", то учащийся и его родитель могут в системе АСУ РСО в разделе "Персональные настройки" увидеть номер этого сертификата.
