Форма №ОШ-1. пп.8-12
В пунктах 8-12 указываются сведения о школьной библиотеке (количество книг, количество учебников), группах продленного дня (количество групп, число обучающихся в них), сведения по количеству групп (для школ-интернатов для детей с ограниченными возможностями здоровья), сведения о логопедическом кабинете, данные о наличие попечительского совета, сведения о платных услугах и численности обучающихся платно.
Форма № ОШ-1 заполняется один раз в год, подписывается руководителем общеобразовательного учреждения и должностным лицом, ответственным за заполнение формы, с указанием номера контактного телефона и даты заполнения, и сдается 7 сентября.

Авторасчет
В системе "Сетевой Город" на каждой из страниц Формы № ОШ-1, кроме титульного листа, есть возможность автоматического заполнения полей с помощью кнопки Авторасчет. Данные можно потом при необходимости исправить или ввести вручную.

Печать сведений и переход на другие страницы
Сверху и снизу этой страницы есть ссылки на другие пункты Формы № ОШ-1. Для перехода на них нажмите на соответствующую ссылку левой кнопкой мыши: Титульный лист : пп.1-2 : пп.3-4 : пп.5-7 : пп.8-12 : пп.13-14 : пп.15-16 : п.17
Введенные сведения можно распечатать. Для этого нажмите кнопку Для печати. В новом открывшемся окне броузера нажмите кнопку Печать (Print).
