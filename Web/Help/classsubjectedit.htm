Связать предмет и класс
Для того чтобы связать предмет с классом, по предмету должны быть проставлены часы для соответствующей параллели в Учебном плане, и должен быть хотя бы один учитель, который преподает этот предмет.

Для преподавателя для предмета необходимо перейти на экран Управление->Сотрудники, нажать на нужную фамилию и в строке Преподаваемые предметы ввести необходимые сведения.
