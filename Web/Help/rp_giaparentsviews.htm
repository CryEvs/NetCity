Ознакомление родителей с результатами ЕГЭ/ОГЭ

С помощью этого отчёта сотрудники школы могут видеть, сколько родителей ознакомилось с результатами ЕГЭ или ОГЭ.
Чтобы узнать, кто именно из родителей ознакомился, - используйте другой отчёт "Ознакомление родителей с результатами ЕГЭ/ОГЭ (персональный список)".

Фактом ознакомления считается просмотр родителем результатов ЕГЭ/ОГЭ по своему ребёнку. Ознакомление самого ученика со своими результатами - не учитывается. Учитывается только просмотр родителем под своей учётной записью в системе: как только родитель перешёл в экран "Результаты сдачи ГИА", на этом экране выбрал предмет, затем выбрал ребёнка (если у него более одного ребёнка) - результаты ученика по данному предмету считаются просмотренными.

Выберите вид экзамена:
·ЕГЭ - для получения отчёта по 11-м (12-м) классам,  
·ОГЭ - для получения отчёта по 9-м классам.

Кол-во учеников 9 классов:
графа выводит количество учеников, результаты которых загружены в систему по данному предмету (сотрудниками Управления образования с помощью импорта файла).

Кол-во родителей 9 классов, ознакомленных с результатами ОГЭ:
графа выводит количество учеников, родители которых ознакомлены.
Причём достаточно, чтобы хотя бы один родитель, прикреплённых к ученику, ознакомился с результатом. Например, если к ребёнку прикреплено 2 родителя, - то если просмотрели один или оба, всё равно при подсчёте учитывается 1.

% родителей 9 классов, ознакомленных с результатами ОГЭ:
процентное соотношение между двумя предыдущими графами.
