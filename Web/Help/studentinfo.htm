Сведения об ученике
На этом экране представлена краткая анкета ученика, с указанием его ФИО, даты рождения, пола, номера телефона, e-mail и информации о родителях. В строке категория вы можете выбрать одно из двух значений:

·Доступные для зачисления - ученик может быть зачислен в любую из школ, расположенных на данном сервере системы "Сетевой Город";  
·Архив - ученики, которые по разным причинам "вышли" за пределы системы (например, переехали в другой город) и являются недоступными на экране Выпускники и выбывшие, т.е. их нельзя зачислить в какую-либо школу в системе.  

Изменить категорию с Доступные для зачисления на Архив может только пользователь с ролью администратора системы в той школе, из которой ученик выбыл. Для всех остальных эта строка будет доступна в режиме только чтения.

Изменить категорию обратно - с Архив на Доступные для зачисления - может только пользователь Администратор сервера "Сетевого Города".

Причины недоступности
Для категории Архив можно указать причину недоступности:
·поступил на работу и больше не учится,  
·поступил в ВУЗ,  
·поступил в ПОО (профессиональная образовательная организация),  
·переезд в другой город,  
·естественная убыль (т.е. смерть).
