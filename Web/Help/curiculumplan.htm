Учебный план


На экране Учебный план необходимо ввести часы по всем предметам, по каждой компоненте для каждого класса в отдельности. Для того, чтобы можно было задавать часы в параллели, необходимо:
1) чтобы эта параллель была отмечена галочкой на экране Планирование->Профили,
2) чтобы для этой параллели была задана нагрузка на экране Планирование->Нагрузка.

Заполнение учебного плана облегчает впоследствии целый ряд операций:
·при создании нового класса с ним автоматически связывается набор предметов согласно учебному плану;  
·при составлении расписания система автоматически предложит создать столько занятий в неделю, сколько было задано в учебном плане;  
·в отчётах "Учёт учебных часов учителя" и "Распечатка классного журнала" автоматически выводится количество часов согласно учебному плану.  

Учебный план может быть разным в различных учебных периодах. Рекомендуется заполнить учебный план целиком сначала для первого периода (например, если в школе используются четверти, то для 1-й четверти), а затем скопировать учебный план в следующие периоды.

В таблице учебного плана также выводится Общая педагогическая нагрузка для каждого класса в отдельности.

Примечание: Если выбрать в выпадающем списке Группы предметов значение Выводить только название группы, то в учебном плане будет показываться только название группы без расшифровки того, какие предметы в группу входят. Подробнее см. Как избежать превышения нагрузки по предмету в учебном плане?

Редактирование учебного плана
Чтобы внести изменения в учебный план, необходимо выбрать в выпадающем списке Вид значение По классам и в выпадающем списке Группы предметов - значение Выводить все предметы из группы. После этих действий учебный план станет доступен для редактирования.

В процессе редактирования, для вашего удобства, последние изменённые ячейки подсвечиваются.

Как удалить в учебном плане часы по предмету
·Чтобы стереть учебный план полностью в выбранном учебном периоде: нажмите кнопку Очистить учебный план, затем кнопку Сохранить.  
·Чтобы удалить из учебного плана отдельные часы: очистите нужную ячейку на пересечении класса и предмета (не ставить 0, а именно стереть все цифры из ячейки), затем нажмите кнопку Сохранить.  

Внимание: Удалить часы из учебного плана (а также очистить его полностью) можно только в случае, если нет сведений о расписании, заданий и оценок по удаляемым классам и предметам.
Учебный план можно просмотреть в удобном для печати виде, нажав кнопку . В новом открывшемся окне браузера нажмите кнопку Печать (Print). Кроме того, есть возможность экспорта учебного плана в таблицу формата MS Excel с помощью кнопки . Подробнее об этой возможности вы можете прочитать на странице Экспорт данных из системы "Сетевой Город".
