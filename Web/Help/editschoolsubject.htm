Создание/Редактирование предмета

Создание нового предмета
При создании нового предмета, необходимо ввести названия предмета - полное и сокращённое, а также желательно выбрать образовательную область, к которой относится создаваемый предмет. Сокращённое название предмета нужно для более компактного вывода расписания и отчётов.

Что такое "общий предмет"?
Для составления сводных отчётов Управления образования по всем школам, в системе существует единый, унифицированный список предметов для всех школ. Это и есть список "общих предметов". Каждый предмет в вашей школе должен соответствовать определённому "общему предмету" в этом списке. Например, если ваш предмет называется "Алгебра и начала анализа", то он должен соответствовать в списке общему предмету "Алгебра".

Важно: для корректного формирования "Отчёта о потенциальных медалистах" должны быть выполнены условия:
1.Для предметов из федерального учебного плана должны быть обязательно указаны соответствующие "общие предметы". (Например, предмет "Русский язык" в вашей школе должен соответствовать общему предмету "Русский язык".)  
2.Для элективных курсов (предметы по выбору, которые изучают в 10-11 кл.) должны быть указаны "общие предметы" не из федерального учебного плана. (Например, элективный предмет "Русский язык (электив)" в вашей школе может соответствовать общему предмету "Русский язык (электив)", но ни в коем случае не общему предмету "Русский язык".)

Редактирование преподавателей и создание подгрупп
В качестве преподавателя можно назначить любого сотрудника, имеющего роль учителя. Здесь не указываются конкретные классы, в которых работают эти преподаватели, - указать их в конкретных классах можно на экране "Обучение -> Предметы".

Подгруппы предмета также создаются здесь без указания классов. Чтобы разделить на подгруппы конкретный класс, см. Инструкцию по созданию подгрупп по предметам.
