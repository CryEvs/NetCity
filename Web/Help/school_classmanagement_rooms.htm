Список кабинетов и других помещений школы

Список кабинетов
Список кабинетов используется при составлении расписания вручную на экране Составить расписание, а также при использовании программ Хронограф, Ректор, AVTOR, помогающих составить расписание автоматически. Для ведения списка кабинетов у пользователя должно быть право доступа Составлять расписание и определять список кабинетов школы. По умолчанию, это право доступа есть только у пользователей с ролью завуча.

Кроме кабинетов, в список должны быть включены спортзалы, бассейны, мастерские и прочие помещения школы.

Признак "Учебное помещение"
Если отмечен признак "Учебное помещение", то данный кабинет разрешён к использованию при составлении расписания.
Возможна ситуация, когда невозможно снять данный признак: это значит, что кабинет уже используется в расписании в текущем учебном году.

Поле "Максимальная наполняемость"
Данное поле означает максимальную наполняемость (вместимость) кабинета по СанПиН. Значение, введённое здесь, также выводится на экране Обучение -> Классы.

Объединение кабинетов
Иногда возникает ситуация, когда один и тот же кабинет введен сразу под несколькими названиями. Например, актовый зал назван а/з, а\з и акт.зал. Чтобы исправить опечатки и объединить кабинеты с разными названиями, надо во всех строках, обозначающих данный кабинет, ввести одинаковое название, и нажать кнопку Сохранить. На экране появится предупреждение:

Названия кабинетов совпадают. Вы хотите перенести уроки в один кабинет?

После нажатия кнопки Оk, данные кабинеты объединятся в один. Остальные свойства (вместимость, этаж) берутся у того кабинета, который был введен последним в список.
