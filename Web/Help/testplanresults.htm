Протокол контрольной работы

Протокол выполнения контрольной работы возможно заполнять и впоследствии анализировать для следующих типов заданий:
·Контрольная работа  
·Тематическая работа  
·Диктант (для этого типа реализована отдельная форма протокола!)  
·Тестирование  
(независимо от настоящего типа задания, в названии используются именно слова "контрольная работа" для унификации)

Заполнение протокола контрольной работы
Протоколы контрольных работ заполняет учитель-предметник для каждого задания в отдельности. Для этого нужно выполнить следующие действия:
1) открыть экран «Классный журнал»,  
2) выбрать дату урока, который содержит один из указанных четырёх типов заданий:  



Для создания протокола контрольной работы нажмите иконку «Протокол контрольной работы»:



Для нового (пустого) задания будет выведено сообщение, что необходимо сформировать план контрольной работы. После его формирования можно заполнять сам протокол, он имеет вид таблицы результатов для каждого ученика:



Столбцы с номерами соответствуют номерам заданий из плана контрольной работы. Колонка «Итого баллов» отображает суммированные баллы по всем заданиям.
Колонка «Оценка» – это выставленная учителем оценка в экране Классный журнал -> Выставить оценки.

Почему протокол контрольной работы может быть закрыт для редактирования?
В случае, если пользователь не является преподавателем предмета в классе, но имеет права на просмотр журнала, ему будет доступен просмотр Протокола контрольной работы и Плана контрольной работы без возможности редактирования.

Отличие заданий типа "Диктант"
Для типа задания "Диктант" реализована отдельная форма ввода плана контрольной работы.
Если для типов "Контрольная работа", "Срезовая работа", "Тестирование" вводятся баллы, которые ученик набрал за выполненное задание, - то в диктанте вводится количество ошибок определённого вида: орфографические или пунктуационные. Протокол контрольной работы тоже заполняется с учётом этих видов ошибок.
