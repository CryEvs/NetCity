Программы

Программы внеурочной деятельности - аналогичны обычным предметам, только программы не включаются в учебный план школы и не появляются в списке обычных предметов.

Программы используются при составлении Плана внеурочной деятельности.

Для каждой программы требуется выбрать одно из направлений внеурочной деятельности:
·Спортивно-оздоровительное  
·Общекультурное  
·Общеинтеллектуальное  
·Духовно-нравственное  
·Социальное
