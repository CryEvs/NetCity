Редактирование класса

На этом экране можно изменить параметры класса.

Название класса
Можно отредактировать только литеру класса (точнее, ту часть названия, которая следует за номером параллели). Причём это возможно только для класса с типом учебного плана "Классический". (Для ИУП-классов изменить название в течение учебного года невозможно.)
После изменения названия класса, оно изменится во всех разделах системы в текущем учебном году.

Профиль класса
Сменить профиль у класса вы можете только до тех пор, пока в данном классе не выставлено ни одной итоговой отметки (за четверти/триместры/полугодия), а также нет расписания.
Если же выставлены итоговые отметки или есть расписание, то сменить профиль класса можно будет только при переходе на новый учебный год на этапе "Формирования классов следующего года".

При изменении профиля для класса - доступны только профили с одним типом учебного периода.

Тип класса
Поле Тип класса может принимать следующие значения:
·Общеобразовательный;  
·Углубленное изучение предметов;  
·Профильное обучение;  
·Профильный общеобразовательный;  
·Профильный углубленный;  
·Специальное коррекционное обучение.  
Эта информация используется при формировании административных отчётов, например, "Информация о численности детей".

Тип учебного плана для класса
Поле Учебный план определяет тип учебного плана: "Классический" или "Индивидуальный". Сменить тип «Классический» на «Индивидуальный» - можно в любой момент времени, независимо от наличия учащихся в классе или от наличия данных об успеваемости. Однако, обратное изменение типа – с «Индивидуального» на «Классический» - возможно не всегда, а только до того момента, пока в класс не зачислены учащиеся.
Вы можете подробнее узнать о внедрении индивидуальных учебных планов:
·с начала учебного года;  
·не с начала учебного года (при наличии текущей успеваемости, посещаемости, расписания).
