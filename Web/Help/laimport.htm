Создание учебных курсов
Система "Сетевой Город" предоставляет вам мощную возможность введения в базу данных собственных учебных курсов. Чтобы иметь такую возможность, у вас должно быть отмечено право доступа Вводить собственные учебные курсы.

Чтобы ввести свой учебный курс, вам необходимо создать с помощью утилиты "Импорт курсов" файл в формате mdb. Как это сделать, читайте на экране Учебные курсы по кнопке Импорт учебных курсов. Там же есть ссылки на программу импорта курсов и руководство по ее использованию.
