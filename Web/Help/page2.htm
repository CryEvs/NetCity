Страница формы

На этом экране можно заполнить и сохранить страницу формы госстатотчётности.

На большинстве страниц формы есть кнопка Авторасчёт, которая позволяет автоматически заполнить поля данными из системы. После авторасчёта данные не сохраняются в базе данных, а только отображаются на экране в соответствующих полях. Таким образом, есть возможность отменить авторасчёт, просто не сохраняя результаты его действий. Чтобы содержимое полей было сохранено в базе данных системы, нужно явно нажать кнопку Сохранить.

Кнопка Для печати позволяет вывести страницу на принтер с помощью стандартных средств программы-браузера.

Чтобы сохранить форму в формате Excel, перейдите на титульный лист формы, где воспользуйтесь кнопкой Экспорт в Excel.
